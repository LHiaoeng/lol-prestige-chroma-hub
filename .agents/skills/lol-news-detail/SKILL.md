# 获取 LOL 官网新闻详情

## 触发条件

用户要求获取、抓取、阅读英雄联盟官网新闻详情页的内容，或提供了 `https://lol.qq.com/news/detail.shtml?docid=xxx` 格式的链接。

## 页面特征

- **URL 格式**：`https://lol.qq.com/news/detail.shtml?docid={docid}`
- **编码**：GBK
- **渲染方式**：JavaScript 动态渲染（SPA），内容通过 `ArticleDetail` 模块异步加载
- **关键标识**：页面包含 `ArticleDetail.doLike()`、`#content` 容器、`.subnav` 导航等元素

## 获取流程

### 第一步：使用浏览器代理获取页面内容

由于页面内容通过 JavaScript 动态加载，**必须使用 ComputerUse 浏览器代理**访问页面：

```
使用 ComputerUse 浏览器代理打开以下 URL：
https://lol.qq.com/news/detail.shtml?docid={docid}

等待页面完全加载后（至少等待 3-5 秒），执行以下操作：
1. 截取页面截图以确认页面已加载
2. 提取页面中的文本内容
```

向浏览器代理发送的 prompt 模板：

```
请打开这个英雄联盟官网新闻页面：{URL}

等待页面完全加载后（至少等待 5 秒），然后：
1. 截取页面截图
2. 提取并返回以下信息：
   - 文章标题（页面主标题，通常在 h1 或标题区域）
   - 发布时间（通常在标题下方）
   - 文章正文的完整文本内容（从上到下，按段落分隔）
   - 正文中所有图片的 URL（img 标签的 src 属性）
   - 文章分类/标签（如：新闻、公告、赛事等）

请以结构化格式返回所有内容。
```

### 第二步：结构化整理

将浏览器代理返回的内容整理为以下结构：

```
## 新闻详情

- **标题**：{文章标题}
- **发布时间**：{YYYY-MM-DD 或原始格式}
- **分类**：{新闻/公告/赛事/攻略等}
- **来源 URL**：{原始链接}

### 正文内容

{按段落整理的正文文本}

### 图片列表

1. {图片1 URL} - {图片描述（如有）}
2. {图片2 URL} - {图片描述（如有）}
...
```

### 第三步：内容应用（可选）

如果获取的新闻内容将用于博客文章创作：

1. **提取关键信息**：标题、核心公告内容、相关数据
2. **图片处理**：如需在博客中使用，下载图片后用 `compress-image` skill 压缩到 ≤ 1MB
3. **内容改写**：按照 `blog-article` skill 的写作规范进行双语内容创作
4. **标注来源**：在文章中用 `<aside class="official-sources">` 标注官网原文链接

## 备用方案

如果浏览器代理不可用，尝试以下替代方式：

### 方案 A：WebFetch 直接获取

```
使用 WebFetch 工具访问 URL（注意：由于页面是 SPA，可能无法获取完整内容）
```

WebFetch 可能只返回页面骨架而无法获取动态内容。如果返回的内容中不包含文章正文，则必须使用浏览器代理。

### 方案 B：搜索获取摘要

```
使用 WebSearch 搜索：site:lol.qq.com {docid} 或文章标题关键词
从搜索结果摘要中获取部分内容
```

### 方案 C：NGA 搬运

许多 LOL 官网新闻会被玩家搬运到 NGA 论坛（`bbs.nga.cn` / `ngabbs.com`），格式为纯文本：

```
使用 WebSearch 搜索：site:ngabbs.com OR site:bbs.nga.cn {docid}
使用 WebFetch 获取 NGA 帖子内容（纯文本，更容易解析）
```

NGA 搬运帖通常包含：
- 原文链接（含 docid）
- 完整的中文正文内容
- 附件图片

## URL 解析

从 URL 中提取 `docid`：

```
URL 格式：https://lol.qq.com/news/detail.shtml?docid=10585262506504136031
docid：10585262506504136031
```

`docid` 是新闻的唯一标识符，可用于：
- 搜索该新闻的搬运/转载
- 构建完整 URL
- 在博客元数据中作为来源引用

## 注意事项

- 页面使用 GBK 编码，部分工具可能返回乱码，这是正常现象
- 页面包含登录提示、客户端引导等非内容区域，提取时需过滤
- 图片 URL 通常为 `//game.gtimg.cn/images/lol/...` 格式（协议相对路径），使用时需补全 `https:`
- 部分新闻可能包含视频，视频 URL 通常在 `//lol.qq.com/v/v2/detail.shtml?docid=xxx`
- 官网新闻内容版权归 Riot Games / 腾讯游戏所有，在博客中使用时需标注来源
