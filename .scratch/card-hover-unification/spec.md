# 全站卡片悬停效果对齐 Antdv Next

## Problem Statement

站内卡片使用多种悬停效果，包括金色描边、背景提亮、上移和封面缩放。通用 Card 还需要调用方开启悬停状态。访客跨页面浏览时，同类操作得到不同的视觉反馈。

## Solution

全站卡片在同一次交付中采用 Antdv Next Card 的 hoverable 效果，本站默认开启。鼠标悬停时显示手形光标，已有边框变透明，并显示与上游语义对应的卡片阴影。边框颜色和阴影按上游方式过渡，卡片位置、背景和封面尺寸保持稳定。

## User Stories

1. 作为桌面访客，我希望所有卡片默认提供一致的悬停反馈，以便跨页面浏览时得到相同体验。
2. 作为臻彩原画图鉴访客，我希望悬停时边框变透明并显示阴影，以便视觉反馈与其他目录一致。
3. 作为皮肤和 PBE 资料访客，我希望静态入口与动态结果里的卡片悬停一致，以便切换页面或筛选后体验连贯。
4. 作为英雄、皮肤系列或皮肤宇宙访客，我希望卡片遵循统一的悬停规则，以便不同资料都能用同样的方式浏览。
5. 作为云顶之弈访客，我希望小小英雄和棋盘卡的外框反馈一致，以便悬停时仍可使用现有预览操作。
6. 作为博客读者，我希望悬停时卡片和封面保持原位及原尺寸，以便阅读时视线稳定。
7. 作为使用卡片操作的访客，我希望预览、下载和详情入口继续可用，以便完成原来的任务。
8. 作为标题被截断的卡片访客，我希望仍能通过标题 Tooltip 查看完整名称，以便识别条目。
9. 作为键盘用户，我希望卡片链接和按钮保有清晰的焦点反馈，以便使用现有操作。
10. 作为触屏用户，我希望轻触可正常执行现有操作，以便无需依赖鼠标悬停。
11. 作为网站维护者，我希望新卡片复用默认的悬停规则，以便全站规范长期一致。

## Implementation Decisions

- 以项目固定提交的 Card 为基准，复用主题中与上游卡片阴影及过渡时间对应的值。Card 和现有业务卡共用同一套默认悬停规则。本站默认开启是明确的产品差异。对有边框的卡片只改变边框色，保留边框占位。 [上游 Card 样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/card/style/index.ts#L351)
- 覆盖通用 Card、首页和目录臻彩、动态炫彩和皮肤引用、皮肤图鉴各视图、PBE 图文及纯文字卡、英雄、皮肤系列、皮肤宇宙、小小英雄、棋盘，以及博客相关卡片。清单用于验收，实施时发现的其他卡片也须同步接入。
- 移除用于装饰的局部悬停覆盖，包括描金、背景提亮、上移和封面放大。清理仅服务于旧效果的过渡属性。媒体预览提示、操作入口显隐及截断标题 Tooltip 保留各自的交互语义。
- 保留卡片现有链接、按钮、焦点可见样式和触屏入口。手形光标属于悬停样式，卡片容器的点击行为和可访问语义沿用现有契约。
- 交付时同步更新设计规范并记录与上游的默认值差异。

## Testing Decisions

- 以实际页面的可观察表现为主，沿用项目对共享组件与页面的验收方式。检查中英文、桌面鼠标及手机触屏，覆盖通用 Card、静态首屏和动态列表，包括筛选或追加结果。
- 比较鼠标进入与移出前后的光标、边框颜色、阴影及过渡属性，确认默认即生效。比较两种状态的卡片几何位置、背景和封面尺寸，确认旧装饰效果已移除。
- 验证标题 Tooltip、预览、下载、导航和键盘焦点仍可用，并在触屏检查操作入口。复用现有首页目录和运行时卡片交互测试，浏览器负责验证 CSS 悬停效果。
- 按全站范围逐项核对现有用法，并运行相关测试和类型检查。

## Out of Scope

- 非卡片控件的悬停样式、卡片标题排版规格、卡片数据及导航结构。
- 新增整卡点击动作或重做卡片布局。

## Further Notes

- 本规格与卡片标题统一规格配套。整卡的悬停视觉反馈与截断标题 Tooltip 可以同时生效。
