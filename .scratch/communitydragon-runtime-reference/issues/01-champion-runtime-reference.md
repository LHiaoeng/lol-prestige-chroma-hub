# 01: 建立英雄运行时资料闭环

**What to build:** 让访客能够在中英文页面中浏览和打开英雄资料，并在同一页面壳内可靠地切换 PBE 与正式服。该切片同时建立后续实体复用的 CommunityDragon 运行时资料边界，但以完整可操作的英雄列表和详情作为可演示结果。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 英文页面只读取 `default` 区域数据视图，中文页面只读取 `zh_cn`，字段缺失时不跨区域或跨通道补值。
- [ ] 英雄列表支持搜索、排序和分页；英雄详情使用数字 ID 定位，并展示该英雄的基本资料与皮肤正向集合。
- [ ] 默认通道为 PBE，显式 `channel=latest` 切换正式服；语言切换、站内导航、分享链接及浏览器前进后退均保留有效状态。
- [ ] 非法 ID 或通道显示链接无效且不发起请求；不存在、网络失败、HTTP 失败和响应校验失败具有可区分且可重试的用户状态。
- [ ] 通道切换在目标数据成功后才更新内容和 URL；失败时保留原内容与原 URL，旧请求或迟到响应不会覆盖当前状态。
- [ ] 运行时资料边界通过小型 `list`/`get` 行为封装安全 URL、请求、Schema 校验、资源路径解析、页面内请求去重、取消和结构化错误，并允许测试注入请求实现。
- [ ] 页面显示数据通道、区域数据视图、加载时间和原始来源链接；加载、失败与重试状态对键盘和辅助技术可感知，无脚本状态仍提供标题、导航、来源说明和启用脚本提示。
- [ ] 自动化测试使用固定夹具与假请求覆盖两个通道、两个区域视图、URL 状态、请求取消、竞争响应、共享静态资源和无跨区域回退，常规测试不访问真实 CommunityDragon。
