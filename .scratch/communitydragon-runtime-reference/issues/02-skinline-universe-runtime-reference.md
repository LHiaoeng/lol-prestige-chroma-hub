# 02: 建立系列与宇宙资料导航

**What to build:** 让访客能够通过中英文运行时页面浏览皮肤系列和皮肤宇宙，并沿着明确、低成本的数据方向在系列与宇宙之间导航，而不制造完整皮肤反向目录。

**Blocked by:** 01/建立英雄运行时资料闭环。

**Status:** ready-for-agent

- [ ] 皮肤系列和皮肤宇宙均提供可用的列表与数字 ID 详情入口，并复用既有 PBE/Latest、语言、URL、错误和重试行为。
- [ ] 系列详情展示自身区域资料及所属宇宙；宇宙详情展示自身区域资料及所属系列。
- [ ] 系列和宇宙页面不读取完整皮肤目录，也不声称展示完整的皮肤或英雄反向集合。
- [ ] 核心实体成功后才加载关联资料；关联失败只影响对应区域，不移除核心详情。
- [ ] 区域记录引用的共享图片、视频或图标能够按资源规则显示，但缺失文本和业务字段不会从另一地区补值。
- [ ] 页面显示准确的来源透明信息，并具备稳定骨架、可访问加载状态、媒体失败降级和无脚本说明。
- [ ] 自动化测试覆盖列表、详情、系列到宇宙及宇宙到系列的导航、区域隔离、通道切换、关联失败和禁止完整皮肤目录请求。
