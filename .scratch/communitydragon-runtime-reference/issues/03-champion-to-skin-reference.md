# 03: 完成英雄到皮肤的资料链路

**What to build:** 让访客从英雄详情中的皮肤集合进入准确的皮肤详情，并在核心皮肤资料出现后渐进浏览对应系列和宇宙，全程避免下载完整皮肤目录。

**Blocked by:** 01/建立英雄运行时资料闭环；02/建立系列与宇宙资料导航。

**Status:** ready-for-agent

- [ ] 英雄详情中的皮肤入口同时携带皮肤 ID 与英雄定位提示，并在语言或数据通道切换后保持有效。
- [ ] 皮肤详情要求正安全整数参数，通过英雄定位提示读取对应英雄资料，再按皮肤 ID 查找并验证目标身份。
- [ ] 缺失英雄定位提示时只允许读取必要索引；正常路径及回退路径均不得依据皮肤 ID 格式猜测英雄，也不得请求完整 `skins.json`。
- [ ] 皮肤核心资料优先显示，系列和宇宙随后独立加载；关联请求最多三个并发，切换、重试或离开页面时旧请求会被取消。
- [ ] 系列和宇宙关联提供有效导航；关联失败不影响核心资料，主媒体失败时文字仍可阅读并使用本地占位或隐藏损坏媒体。
- [ ] 目标通道没有该皮肤时显示明确的不存在状态，不回退到原通道或另一地区的数据。
- [ ] 在真实浏览器中，中英文用户能够从英雄详情进入皮肤详情，看到核心资料和渐进关联，切换 `pbe` / `latest` 并恢复关联或媒体失败，且没有阻止操作的控制台异常。
- [ ] 自动化测试覆盖参数校验、英雄定位、皮肤身份复核、定位不一致、目标不存在、关联渐进加载、并发与取消、媒体失败，以及不请求完整皮肤目录。
