# 04: 增强静态臻彩与覆盖率文章

**What to build:** 在保持静态臻彩和博客正文完整、可索引且可离线构建的前提下，为它们加入可失败的 CommunityDragon 辅助资料和可审计的数据维护流程。

**Blocked by:** 01/建立英雄运行时资料闭环；03/完成英雄到皮肤的资料链路。

**Status:** ready-for-agent

- [ ] 静态臻彩详情无需 CommunityDragon 即可完整展示正文、图片、主要操作和 SEO 内容。
- [ ] 静态正文完成后自动加载精确关联的英雄与基础皮肤资料；失败只影响补充区，并提供轻量、可访问的重试反馈。
- [ ] `channel=latest` 只改变 CommunityDragon 补充资料及其后续运行时链接，不改变静态臻彩事实。
- [ ] 英雄覆盖率文章从已提交的仓库快照生成完整静态正文，普通开发和发布构建均不会在线更新快照。
- [ ] 显式维护流程能够更新快照，并记录来源 URL、数据通道、区域数据视图、抓取时间和内容版本；非法或不完整快照会使维护流程失败。
- [ ] 浏览器可以显式刷新覆盖率辅助数据；刷新失败时保留并继续展示仓库快照。
- [ ] 自动化测试证明静态正文先于增强存在、补充失败不损害主要内容、通道只影响补充区、快照可重复构建且浏览器刷新失败会保留原内容。
