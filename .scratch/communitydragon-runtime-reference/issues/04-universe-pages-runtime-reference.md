# 04: 拆分宇宙列表与详情页

**What to build:** 让中英文宇宙目录和单个宇宙资料使用两个独立页面，并完成宇宙详情与已经可用的皮肤系列详情之间的普通跨页面导航。

**Blocked by:** 01/修复英雄列表与运行时页面基础；03/拆分皮肤系列列表与详情页。

**Status:** completed

- [x] 中英文分别生成独立宇宙列表壳和宇宙详情壳，不为每个宇宙生成静态 HTML。
- [x] 宇宙列表支持名称搜索、稳定排序和分页；宇宙卡片使用普通链接进入相同语言和数据通道下的宇宙详情。
- [x] 宇宙列表永远只解析列表状态，旧的列表页 `?id=` 形式不会在当前页面渲染宇宙详情。
- [x] 宇宙详情要求合法数字 ID，展示当前区域视图中的名称、描述和媒体；非法或不存在的宇宙具有明确状态。
- [x] 宇宙详情初始 HTML 带 `noindex`，提供返回宇宙列表的链接，并用普通链接导航到所属系列详情。
- [x] 系列详情同步完成到宇宙详情的反向页面导航，但双方都不读取完整皮肤目录或承诺完整皮肤、英雄反向集合。
- [x] 在真实浏览器中，中英文宇宙列表、宇宙详情和系列详情之间能够加载、导航、刷新、切换通道和恢复失败，无阻断性控制台异常。
- [x] 自动化测试覆盖两个页面模式、跨实体导航、参数验证、区域隔离、渐进关联失败、初始 `noindex` 和禁止完整皮肤目录请求。

验证记录：`pnpm test`（36 个测试文件、260 个测试）和 `pnpm typecheck` 通过；真实浏览器验收覆盖中英文列表/详情、搜索、`latest`、语言切换、前进后退、非法 ID、404 重试及控制台日志。
