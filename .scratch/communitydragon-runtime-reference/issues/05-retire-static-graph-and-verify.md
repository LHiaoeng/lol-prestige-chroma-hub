# 05: 移除旧图谱并完成离线验收

**What to build:** 完成从构建期 CommunityDragon 图谱到浏览器运行时资料的收缩，确保发布不依赖外部源站、搜索引擎只看到预期静态内容，并向访客清楚说明第三方请求边界。

**Blocked by:** 01/建立英雄运行时资料闭环；02/建立系列与宇宙资料导航；03/完成英雄到皮肤的资料链路；04/增强静态臻彩与覆盖率文章。

**Status:** ready-for-agent

- [ ] 移除完整 `pbe` 图谱、构建期 CommunityDragon 实体抓取以及只服务旧图谱的合并和专用命名，且不存在仍引用旧行为的消费者。
- [ ] 不再为英雄、普通皮肤、系列和宇宙生成逐实体静态 HTML；旧 CommunityDragon 实体详情 URL 不提供兼容页或跳转，并永久返回 404。
- [ ] 动态详情统一 `noindex`，不进入 sitemap；动态目录只保留必要静态说明与自身 canonical。
- [ ] 完整 CommunityDragon 目录 JSON 和仓库私有目录数据均不会进入公开产物。
- [ ] 隐私说明明确披露浏览器会直接请求 CommunityDragon 资料与媒体，请求不携带凭据并尽量省略 Referer。
- [ ] 在 CommunityDragon 不可访问的条件下，静态构建和发布产物检查仍成功，首页、博客和臻彩正文保持完整。
- [ ] 发布级验证覆盖中英文入口、`pbe` / `latest` URL、旧 URL 404、动态详情 `noindex`、sitemap 边界、公开产物审计及静态内容离线可用性。
- [ ] CommunityDragon 通道相关 UI、无障碍文案、测试、领域词汇、资源指南、ADR、规格、任务和最终 HTML 只使用小写 `pbe` / `latest`；语境化审计不会误报普通“最新”、部署环境或游戏服务器用语。
- [ ] 对所有运行时入口执行真实浏览器验收，确认列表、详情、导航、通道切换、前进后退和失败重试可用，并审计阻断性控制台异常和网络失败；仅有通过的单元测试或构建不算完成。
- [ ] 受影响的架构、数据来源、隐私和维护文档与最终行为一致，不保留已失效的构建期说明。
