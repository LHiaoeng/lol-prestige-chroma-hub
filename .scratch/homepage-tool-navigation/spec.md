# 首页工具导航与臻彩目录

## 目标与范围

只调整英文 `/`、简体中文 `/zh-cn/` 首页及首页 SEO。首页保留最新博客，并直接展开可使用的臻彩原画目录，通过导航进入现有游戏资料页；不新增游戏数据来源或运行时接口。

## 已确认的结构

1. 沿用全站 Header。
2. 最新博客模块：沿用现有模块，展示最新 3 篇文章、文章总数与「查看全部」入口，保留分类、标题、日期及中英文链接。
3. 功能导航、臻彩筛选与卡片列表、分页。导航顺序固定为：臻彩原画、PBE 新增、英雄、皮肤系列、皮肤宇宙；臻彩原画在首页为当前项，其余项进入现有页面。臻彩目录的 `catalog-title` 后紧跟主题色问号图标链接，分别指向当前语言的《什么是臻彩》博客，并提供明确的中英文无障碍名称。臻彩卡片仍进入各自详情页。
4. 沿用全站 Footer。

臻彩筛选与完整列表无需再次点击即可看到；保留现有每页 24 条与分页。“完整显示”指功能和列表直接展开，不指一次加载全部记录。首页不展示独立的 PBE 新皮肤横条、全屏 Hero、可见的大幅首页标题或说明文案。手机导航分两行，全部入口直接可见。

## 展示密度方向

参考 [lol-skin-explorer](https://github.com/BuguoguoLoLCreator/lol-skin-explorer) 的分类导航与密集列表：桌面使用自适应多列方形缩略图，手机使用缩略图加名称的紧凑列表。沿用本站暗色金色视觉、现有臻彩字段、图片来源与详情链接；不复制参考站的技术栈或数据加载方式。具体断点与尺寸待渲染检查。

## 组件边界

- `src/pages/index.astro` 只负责首页 SEO、布局与模块顺序；`src/pages/zh-cn/index.astro` 继续复用同一个首页并传入语言。
- 在 `src/components/` 提取最新博客、功能导航、臻彩目录三个首页模块。最新博客复用现有文章数据与链接规则；功能导航集中维护五个入口；臻彩目录集中维护标题帮助链接、筛选、列表、分页及其浏览器数据与脚本。
- 臻彩目录继续使用现有 `Filters.astro` 与 `PrestigeChromaCard.astro`，Header、Footer 继续由 `BaseLayout.astro` 提供。模块样式随对应组件维护，不为单个标题、卡片或链接再拆组件，也不新增配置层或依赖。
- 中英文入口、问号链接、移动端导航与目录交互应随首页改动做针对性验证。

## 已知风险

最新博客模块提供原创文章入口，但首页不展示说明文案，仍无法保证通过 AdSense 审核；首页改造也无法代替 Google 对全站内容的审核。

## 保留的边界

- 臻彩数据仍来自仓库目录；其他资料页继续按现有规则读取 CommunityDragon。
- 首页保留现有双语路由、筛选、分页、广告边界和导航可达性。
- 只描述已上线的功能，不在首页宣称完整 PBE 字段变化比较、手游或云顶之弈工具已可用。

## 实施结果

2026-10-14：英文与简体中文首页已按上述模块重组。`pnpm release:build` 通过；检查了英文桌面、中文 320px 手机和平板页面，以及导航、筛选、分页和静态首批卡片。
