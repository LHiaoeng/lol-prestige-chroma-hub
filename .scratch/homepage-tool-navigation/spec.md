# 首页工具导航与臻彩目录

## 目标与范围

只调整英文 `/`、简体中文 `/zh-cn/` 首页及首页 SEO。首页保留最新博客，后接同层级的“英雄联盟”区块；区块内以无标题 Card Tabs 导航包住直接展开可使用的臻彩原画目录，通过页签进入现有游戏资料页；不新增游戏数据来源或运行时接口。

## 已确认的结构

1. 沿用全站 Header。
2. 最新博客模块：沿用现有模块，展示最新 3 篇文章、文章总数与「查看全部」入口，保留分类、标题、日期及中英文链接。
3. 功能导航、臻彩筛选与卡片列表、分页。导航顺序固定为：臻彩原画、PBE 新增、英雄、皮肤系列、皮肤宇宙；臻彩原画在首页为当前项，其余项进入现有页面。目录标题由 Alert 代替，简要介绍臻彩，并以外链图标按钮链接到当前语言的《什么是臻彩》博客。臻彩卡片仍进入各自详情页。
4. 沿用全站 Footer。

桌面筛选直接展开，手机筛选默认收起；完整列表无需再次点击即可看到。保留现有每页 24 条与分页。“完整显示”指目录直接呈现，不指一次加载全部记录。首页不展示独立的 PBE 新皮肤横条、全屏 Hero 或可见的大幅首页标题；臻彩介绍使用紧凑 Alert。手机导航分两行，全部入口直接可见。

## 展示密度方向

参考 [lol-skin-explorer](https://github.com/BuguoguoLoLCreator/lol-skin-explorer) 的分类导航与密集列表：桌面使用自适应多列方形缩略图，手机使用缩略图加名称的紧凑列表。沿用本站暗色金色视觉、现有臻彩字段、图片来源与详情链接；不复制参考站的技术栈或数据加载方式。具体断点与尺寸待渲染检查。

## 组件边界

- `src/pages/index.astro` 只负责首页 SEO、布局与模块顺序；`src/pages/zh-cn/index.astro` 继续复用同一个首页并传入语言。
- 在 `src/components/` 提取最新博客、功能导航、臻彩目录三个首页模块。最新博客复用现有文章数据与链接规则；`HomeToolNavigation` 以“英雄联盟”作为与博客同层级的标题，集中维护五个入口，并使用无卡片标题的共享 `Card` Tabs 呈现导航和当前项，页面跳转保留原生链接语义，默认卡片内容容纳臻彩原画目录；`Card` 提供标题、额外操作、封面、尺寸/边框/悬浮样式、加载占位、底部操作及可键盘操作的本地内容页签；臻彩目录顶部 Alert 简述臻彩并用外链图标按钮链接双语指南，Alert 支持状态、标题/描述、图标、关闭、横幅和操作内容，目录其余筛选、列表、分页及浏览器数据与脚本保持在目录模块。
- 臻彩目录继续使用现有 `Filters.astro` 与 `PrestigeChromaCard.astro`，Header、Footer 继续由 `BaseLayout.astro` 提供。模块样式随对应组件维护，不为单个标题、卡片或链接再拆组件，也不新增配置层或依赖。
- 中英文入口、问号链接、移动端导航与目录交互应随首页改动做针对性验证。

## 已知风险

最新博客与臻彩介绍提供原创内容入口，但仍无法保证通过 AdSense 审核；首页改造也无法代替 Google 对全站内容的审核。

## 保留的边界

- 臻彩数据仍来自仓库目录；其他资料页继续按现有规则读取 CommunityDragon。
- 首页保留现有双语路由、筛选、分页、广告边界和导航可达性。
- 只描述已上线的功能，不在首页宣称完整 PBE 字段变化比较、手游或云顶之弈工具已可用。

## 实施结果

2026-10-14：英文与简体中文首页已按上述模块重组。`pnpm release:build` 通过；检查了英文桌面、中文 320px 手机和平板页面，以及导航、筛选、分页和静态首批卡片。首页目录标题现由 Alert 双语介绍替代，并链接至臻彩指南。
