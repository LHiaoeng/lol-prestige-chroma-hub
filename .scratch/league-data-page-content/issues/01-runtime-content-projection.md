# 01: 统一资料投影与阶段规则

**What to build:** 在现有 CommunityDragon 运行时数据边界之上建立可复用的内容投影层，统一字段映射、阶段展开、继承、关系索引和稳定排序，为后续页面提供确定的视图模型。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 以 `codex/communitydragon-runtime-reference` 的运行时 `list` / `get`、本地化视图隔离、数据通道和结构化错误为基线，不重建或削弱这些能力。
- [ ] 定义英雄、包含阶段资料项的皮肤、皮肤系列和皮肤宇宙页面视图模型；关系只使用稳定数字 ID，展示名不参与关联。
- [ ] 每个有效皮肤阶段投影为独立皮肤资料项，具有稳定身份、所属皮肤身份和阶段序号，但不成为新的 CommunityDragon 实体。
- [ ] 阶段名称与媒体优先使用阶段值；说明、稀有度、皮肤系列和皮肤宇宙只从同一本地化视图、同一数据通道的所属皮肤继承。
- [ ] 缺失继承来源时保留明确缺失值，不跨本地化视图或跨数据通道补值；无效与重复阶段按确定规则过滤或报错。
- [ ] 建立英雄、皮肤系列和皮肤宇宙到包含阶段资料项的皮肤索引，并为所有集合提供可重复的稳定排序。
- [ ] 自动化测试覆盖字段映射、本地化视图与数据通道隔离、阶段完整/缺失/重复、继承优先级、关系索引和稳定排序。
- [ ] 更新领域词汇及数据资源说明，使“皮肤阶段”“皮肤本体项”和完整反向集合的定义与实现一致。
