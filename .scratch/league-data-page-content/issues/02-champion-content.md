# 02: 补齐英雄目录与详情内容

**What to build:** 在现有独立中英文英雄目录和详情壳中，补齐两个参考项目展示的英雄资料，同时保持当前导航、数据通道切换和本地化视图隔离行为。

**Blocked by:** 01/统一资料投影与阶段规则。

**Status:** ready-for-agent

- [ ] 英雄目录展示当前本地化记录中的名称、称号、头像或方形图标，以及参考项目共有的定位、资源类型和基础摘要。
- [ ] 英雄详情展示名称、称号、简介、背景故事、主要媒体及可用的结构化分类资料。
- [ ] 英雄详情展示基础属性与成长属性；缺失字段使用明确缺失状态，不以另一本地化视图补齐。
- [ ] 英雄详情展示技能图标、名称、说明和源数据可稳定提供的数值信息。
- [ ] 英雄详情的皮肤集合使用阶段化投影；每个有效阶段可独立进入皮肤详情。
- [ ] 中英文页面分别只消费 `default` 与 `zh_cn` 本地化视图，并保留现有 `pbe` / `latest` 技术值、玩家显示名、普通链接和 URL 状态。
- [ ] 自动化测试覆盖目录字段、详情分区、属性、技能、阶段化皮肤链接、缺失值和本地化视图隔离。
- [ ] 在真实浏览器中验收中英文目录与详情的加载、搜索/筛选、导航、通道切换、失败恢复、键盘操作和移动端长内容。
