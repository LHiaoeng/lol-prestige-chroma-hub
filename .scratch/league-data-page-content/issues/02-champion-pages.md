# 02: 补齐英雄目录与详情

**What to build:** 让现有中英文英雄目录展示名称、头像和定位，并让英雄详情展示英雄名称及该英雄去重后的顶层皮肤资料项的名称、缩略图和本地化稀有度。

**Blocked by:** None (dependency completed: `01-skin-reference-projection.md`).

**Status:** ready-for-human

- [x] 英雄目录卡片展示名称、头像和定位，同时保留现有名称搜索、定位筛选、稳定排序和分页。
- [x] 英雄详情展示英雄名称，不单独展示 `isBase: true` 的英雄默认外观。
- [x] 英雄详情展示去重后的顶层所属皮肤，每项包含名称、缩略图和当前本地化视图的稀有度；任务阶段不在英雄网格中重复展开，仍可从所属皮肤详情访问。
- [x] 英雄详情皮肤卡片使用各自顶层资料项的 `tilePath` 正方形缩略图，不以聚焦原画或其他媒体替代缩略图。
- [x] 皮肤列表默认按发布顺序，并提供参考项目同样的稀有度排序筛选；同稀有度保持稳定顺序。
- [x] 英雄详情成功后不显示“资料加载完成”或等价的英文完成状态文案。
- [x] 所属皮肤链接保留英雄 ID、皮肤 ID 和数据通道；皮肤详情中的阶段链接额外保留阶段 ID，且均使用普通跨页面导航。
- [x] 普通皮肤（`kNoRarity` 或 `regionRarityId: 0`）显示“普通”/`Regular`文字，不显示错误状态或普通皮肤宝石；特殊稀有度使用当前本地化视图的标签与徽章。
- [x] 页面不再展示信息规范未包含的英雄称号、简介、背景故事、属性或技能。
- [x] 自动化测试覆盖目录字段、筛选、英雄详情不显示默认外观和完成状态、顶层皮肤去重、任务阶段不重复展开、缩略图、阶段详情、稀有度、链接参数、本地化隔离和禁止的额外字段。
- [ ] 真实浏览器验收覆盖中英文目录与详情、搜索、筛选、分页、皮肤导航、通道切换、重试、键盘和移动端。
