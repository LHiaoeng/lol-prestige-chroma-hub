# 02: 补齐英雄目录与详情

**What to build:** 让现有中英文英雄目录展示名称、头像和定位，并让英雄详情展示英雄默认外观原画及该英雄全部皮肤资料项的名称、缩略图和本地化稀有度。

**Blocked by:** None (dependency completed: `01-skin-reference-projection.md`).

**Status:** implemented

- [x] 英雄目录卡片展示名称、头像和定位，同时保留现有名称搜索、定位筛选、稳定排序和分页。
- [x] 英雄详情展示英雄名称，并从当前英雄皮肤集合中选择 `isBase: true` 的英雄默认外观原画。
- [x] 英雄详情展示该英雄全部所属皮肤和有效阶段资料项，每项包含名称、缩略图和当前本地化视图的稀有度。
- [x] 所属皮肤链接保留英雄 ID、皮肤 ID 和数据通道；阶段链接额外保留阶段 ID，且均使用普通跨页面导航。
- [x] 缺少英雄默认外观、缩略图或稀有度时显示明确缺失状态，不回退到另一视图或任意皮肤。
- [x] 页面不再展示信息规范未包含的英雄称号、简介、背景故事、属性或技能。
- [x] 自动化测试覆盖目录字段、筛选、英雄默认外观、所属皮肤、阶段、稀有度、链接参数、本地化隔离和禁止的额外字段。
- [ ] 真实浏览器验收覆盖中英文目录与详情、搜索、筛选、分页、皮肤导航、通道切换、重试、键盘和移动端。
