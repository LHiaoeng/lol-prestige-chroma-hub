# 03: 补齐皮肤详情核心资料

**What to build:** 让所属皮肤和有效皮肤阶段都能通过现有皮肤详情壳独立打开，并展示确认的名称、稀有度、描述、所属关系、完整媒体和历史版本原画。

**Blocked by:** 01/建立皮肤资料项投影与阶段定位。

**Status:** implemented

- [x] 皮肤详情继续要求合法英雄 ID 和所属皮肤 ID；可选阶段 ID 必须属于当前皮肤，否则显示链接无效且不猜测目标。
- [x] 所属皮肤详情展示名称、本地化稀有度、描述、所属英雄、皮肤系列和皮肤宇宙。
- [x] 阶段详情优先展示阶段自己的名称和媒体，并按统一投影规则继承允许的所属皮肤字段。
- [x] 页面展示来源实际提供的聚焦原画、未裁剪原画、缩略图、载入图和动态原画；单个媒体失败不移除文字资料。
- [x] 页面展示来源实际提供的历史版本及对应原画，不根据当前媒体或名称推断历史版本。
- [x] 英雄、系列和宇宙关系使用普通链接，保留当前语言和数据通道；关联请求失败不移除核心详情。
- [x] 自动化测试覆盖所属皮肤、阶段、非法参数、字段继承、全部媒体、历史原画、关系导航、局部失败和本地化隔离。
- [ ] 真实浏览器验收覆盖中英文所属皮肤与阶段 URL、刷新、返回、新标签打开、通道切换、错误重试、键盘和移动端。
