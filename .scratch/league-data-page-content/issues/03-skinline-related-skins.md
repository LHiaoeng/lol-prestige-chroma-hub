# 03: 补齐皮肤系列详情的皮肤集合

**What to build:** 让现有中英文皮肤系列详情除自身资料和皮肤宇宙关系外，还能按需展示属于该系列、包含阶段资料项的完整皮肤集合。

**Blocked by:** 01/统一资料投影与阶段规则。

**Status:** ready-for-agent

- [ ] 保留现有皮肤系列列表、独立详情壳、参数校验、`noindex`、数据通道切换和本地化视图隔离行为。
- [ ] 系列目录与详情展示参考项目已有的名称、说明、代表图片和可用关联资料。
- [ ] 仅进入皮肤系列详情时按当前本地化视图和数据通道显式读取建立完整反向集合所需的皮肤数据。
- [ ] 关联集合使用系列稳定 ID 匹配，包含每个有效皮肤阶段，并使用统一稳定排序。
- [ ] 每个关联皮肤项链接到同语言、同数据通道的皮肤详情，并携带正确英雄定位提示。
- [ ] 皮肤集合加载失败时保留系列核心资料并提供独立失败与重试状态；空集合与请求失败可区分。
- [ ] 自动化测试覆盖请求范围、完整关系、阶段展开、链接状态、空集合、失败恢复，并证明其他页面不会因此默认加载完整皮肤数据。
- [ ] 在真实浏览器中验收中英文系列目录、详情、完整皮肤集合、皮肤导航、通道切换、返回与失败恢复。
