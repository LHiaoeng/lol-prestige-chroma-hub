# 04: 补齐皮肤本体项、炫彩和第三方入口

**What to build:** 在完整皮肤详情中正确展示皮肤本体项和真正的炫彩，并根据页面本地化视图提供对应参考项目采用的第三方视频、语音和模型入口。

**Blocked by:** 03/补齐皮肤详情核心资料。

**Status:** ready-for-human

- [x] 炫彩数量只统计真正的炫彩记录，不包含皮肤本体项。
- [x] 炫彩区域始终包含当前皮肤或阶段的皮肤本体项；中文显示“默认配色”，英文显示 `Base`。
- [x] 皮肤本体项具有明确的非炫彩可访问说明，不携带炫彩颜色，也不进入炫彩数量。
- [x] 真正的炫彩展示当前本地化视图提供的名称、图片和颜色，缺失事实不从另一视图补齐。
- [x] 颜色组件支持显式非炫彩状态，同时保证首页、臻彩详情和博客的既有调用与表现不变。
- [x] 英文皮肤详情只提供 SkinSpotlights 和 Teemo.GG；简体中文详情只提供布锅锅语音站、哔哩哔哩和布锅锅 3D 模型站。
- [x] 第三方链接使用正确的英雄 ID、完整皮肤 ID 或本地化名称，参数正确编码并带安全外链属性；阶段使用其可验证的所属身份。
- [ ] 自动化与浏览器验收覆盖计数、本体项、颜色、两组第三方入口、特殊字符编码、阶段资料、键盘、屏幕阅读器和移动端。
