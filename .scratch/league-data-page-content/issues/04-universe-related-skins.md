# 04: 补齐皮肤宇宙详情的皮肤集合

**What to build:** 让现有中英文皮肤宇宙详情除自身资料和皮肤系列关系外，还能按需展示属于该皮肤宇宙、包含阶段资料项的完整皮肤集合。

**Blocked by:** 01/统一资料投影与阶段规则；03/补齐皮肤系列详情的皮肤集合。

**Status:** ready-for-agent

- [ ] 保留现有皮肤宇宙列表、独立详情壳、参数校验、`noindex`、数据通道切换和本地化视图隔离行为。
- [ ] 皮肤宇宙目录与详情展示参考项目已有的名称、说明、代表图片和可用关联资料。
- [ ] 仅进入皮肤宇宙详情时按当前本地化视图和数据通道显式读取建立完整反向集合所需的皮肤数据。
- [ ] 关联集合使用皮肤宇宙与皮肤系列稳定 ID 关系匹配，包含每个有效皮肤阶段，并使用统一稳定排序和去重。
- [ ] 每个关联皮肤项链接到同语言、同数据通道的皮肤详情，并携带正确英雄定位提示。
- [ ] 皮肤集合加载失败时保留皮肤宇宙核心资料与皮肤系列导航；空集合与请求失败具有不同状态。
- [ ] 自动化测试覆盖直接/间接关系、去重、阶段展开、请求范围、链接状态、空集合和失败恢复。
- [ ] 在真实浏览器中验收中英文皮肤宇宙目录、详情、皮肤系列关系、完整皮肤集合、普通导航、数据通道切换和移动端内容。
