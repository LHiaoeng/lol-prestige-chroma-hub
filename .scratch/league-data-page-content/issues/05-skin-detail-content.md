# 05: 补齐皮肤详情、炫彩与第三方入口

**What to build:** 扩充现有独立皮肤详情，使所属皮肤和阶段都能展示完整资料、正确的皮肤本体项与炫彩状态，以及随页面语言和本地化视图变化的第三方入口。

**Blocked by:** 01/统一资料投影与阶段规则；02/补齐英雄目录与详情内容。

**Status:** ready-for-agent

- [ ] 保留现有皮肤 ID 加英雄定位提示的详情入口、身份复核、`noindex` 和无皮肤目录边界。
- [ ] 展示名称、所属英雄、说明、稀有度、价格或可获得性、主视觉、载入图、图标及源数据可提供的参考项目字段。
- [ ] 所属皮肤和每个有效阶段都可作为独立目标打开；阶段字段与所属皮肤继承遵循统一投影规则。
- [ ] 展示皮肤系列和皮肤宇宙关系，并用普通链接进入同语言、同数据通道的对应详情。
- [ ] 炫彩计数只包含真正炫彩；炫彩区域同时展示一个皮肤本体项，中文可见文案使用“默认配色”，英文使用 `Base`，无障碍说明明确它不是炫彩。
- [ ] 真正炫彩保留颜色和媒体；现有颜色组件增加非炫彩状态，同时保持原有炫彩调用的默认表现。
- [ ] 英文 / `default` 提供 SkinSpotlights 与 Teemo.GG；简体中文 / `zh_cn` 提供不够够语音、哔哩哔哩皮肤视频搜索和不够够 3D 模型，参数正确编码且不混用。
- [ ] 自动化及真实浏览器验收覆盖所属皮肤/阶段、继承、炫彩计数、皮肤本体项状态、第三方 URL、关联导航、失败状态、键盘和移动端。
