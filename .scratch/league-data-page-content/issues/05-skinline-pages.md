# 05: 补齐皮肤系列及关联皮肤

**What to build:** 让皮肤系列目录严格展示系列名称，并让系列详情展示所属皮肤宇宙及系列内完整的皮肤资料项，同时保持核心资料与大体积关联请求相互独立。

**Blocked by:** 01/建立皮肤资料项投影与阶段定位；03/补齐皮肤详情核心资料。

**Status:** ready-for-human

- [x] 系列目录只展示已确认的系列名称，不把现有图片或描述继续作为页面信息契约。
- [x] 系列详情展示系列名称和所属皮肤宇宙，关系只通过稳定数字 ID 建立。
- [x] 仅进入系列详情时按当前数据通道和本地化视图显式加载完整皮肤资源；其他现有页面不因此增加该请求。
- [x] 系列内展示全部所属皮肤和有效阶段资料项，每项包含名称、缩略图和本地化稀有度。
- [x] 每个资料项链接到可用的所属皮肤或阶段详情，并保留英雄、所属皮肤、阶段和数据通道参数。
- [x] 关联皮肤使用稳定排序；空集合、请求失败和核心系列不存在具有不同状态。
- [x] 完整皮肤请求失败时保留系列名称和宇宙导航，并提供只重试关联集合的操作。
- [x] 自动化验收覆盖严格字段范围、请求边界、完整关系、阶段、排序、空状态、局部失败和重试。
- [ ] 浏览器验收覆盖中英文、键盘和移动端。

## Comments

- 系列列表现仅展示名称；系列详情将宇宙关系和完整皮肤集合拆成独立运行时状态。
- 完整 `skins.json` 仅由系列详情通过 `listSkinlineSkins` 按当前通道和语言加载，皮肤本体与有效阶段统一经过资料项投影、稳定 ID 去重和排序。
- 线上 `skins.json` 不提供 `championId`；按参考 Skin Explorer 使用的 CommunityDragon 皮肤 ID 前缀约定解析英雄归属，并保留源数据提供的 HTTPS 预览视频地址。
- 关联集合失败时保留系列核心资料与宇宙导航，并提供只重试系列皮肤的按钮；空集合显示独立空状态。
- 已补充运行时契约、控制器和 DOM 测试；开发服务器英文桌面端系列 `7` 已实测渲染 22 个关联皮肤，中文、移动端和键盘验收仍待人工确认。
