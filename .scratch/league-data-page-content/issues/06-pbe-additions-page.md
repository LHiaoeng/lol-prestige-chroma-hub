# 06: 建立 PBE 新增页

**What to build:** 新增独立的中英文 PBE 新增页面，在同一页面按实体类型展示当前本地化视图中只存在于 `pbe` 的英雄、包含阶段资料项的皮肤、皮肤系列和皮肤宇宙。

**Blocked by:** 01/统一资料投影与阶段规则；02/补齐英雄目录与详情内容；03/补齐皮肤系列详情的皮肤集合；04/补齐皮肤宇宙详情的皮肤集合；05/补齐皮肤详情、炫彩与第三方入口。

**Status:** ready-for-agent

- [ ] 中英文分别提供职责单一的 PBE 新增页面壳，页面固定比较同一本地化视图的 `pbe` 与 `latest`。
- [ ] 差集按实体类型和稳定 ID 计算；已有 ID 的名称、说明、属性或媒体变化不会进入新增结果。
- [ ] 页面分区展示新增英雄、包含阶段资料项的皮肤、皮肤系列和皮肤宇宙，并为每个分区提供数量与稳定排序。
- [ ] 多阶段皮肤按有效阶段独立展示；阶段只存在于 `pbe` 时能够作为新增皮肤资料项进入对应详情。
- [ ] 每项新增实体使用普通链接进入同语言的既有详情页，并携带复现目标 `pbe` 视图所需的参数。
- [ ] 单个分类为空与全部分类为空均有明确状态；任一必要请求失败时显示可重试错误，不把部分比较冒充完整结果。
- [ ] 完整皮肤数据只由此页面显式请求 `pbe` 与 `latest` 两份同一本地化视图数据，不成为其他入口的默认依赖。
- [ ] 自动化及真实浏览器验收覆盖四类差集、字段变化、阶段、空状态、错误重试、中英文隔离、导航、无障碍和移动端。
