# 06: 补齐皮肤宇宙及分组皮肤

**What to build:** 让皮肤宇宙目录展示宇宙名称及所含皮肤系列，并让宇宙详情展示描述、所属系列和按系列归类的完整皮肤资料项。

**Blocked by:** 05/补齐皮肤系列及关联皮肤。

**Status:** implemented

- [x] 宇宙目录展示名称及其包含的皮肤系列名称；系列名称通过当前视图的稳定 ID 关系解析。
- [x] 宇宙详情展示名称、描述和所属皮肤系列，不把现有宇宙图片继续作为页面信息契约。
- [x] 仅进入宇宙详情时按当前数据通道和本地化视图显式加载完整皮肤资源，并复用系列详情已经验证的请求边界。
- [x] 宇宙内皮肤按所属皮肤系列分组，每个资料项展示名称、缩略图和本地化稀有度。
- [x] 有效阶段作为独立资料项并链接到阶段详情；同一资料项在同一系列分组内按稳定身份去重和排序。
- [x] 缺失系列关系、空皮肤集合、完整皮肤请求失败和核心宇宙不存在具有不同状态。
- [x] 关联皮肤失败不移除宇宙名称、描述和系列导航，并提供独立重试。
- [x] 自动化测试覆盖目录关系、详情描述、分组、去重、阶段、链接、请求边界、失败恢复和中英文状态。
- [ ] 浏览器人工验收覆盖键盘和移动端布局，待用户自行验收。
