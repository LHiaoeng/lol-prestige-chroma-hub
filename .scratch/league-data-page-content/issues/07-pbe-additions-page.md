# 07: 建立 PBE 新增页面

**What to build:** 新增独立中英文 PBE 新增页面，在同一本地化视图内比较 `pbe` 与 `latest`，展示可验证版本信息、总数、分类数量和四类新增实体，并链接到已经可用的 PBE 详情。

**Blocked by:** 02/补齐英雄目录与详情；03/补齐皮肤详情核心资料；05/补齐皮肤系列及关联皮肤；06/补齐皮肤宇宙及分组皮肤。

**Status:** completed

- [x] 中英文分别提供职责单一的 PBE 新增页面壳，并从固定资料导航进入；页面固定比较对应本地化视图的 `pbe` 与 `latest`。
- [x] 页面展示玩家数据通道名称及来源可验证的版本信息；`pbe` / `latest` token 不冒充具体版本号，版本缺失时显示明确状态。
- [x] 差集只按实体类型和顶层稳定 ID 计算；相同 ID 的名称、描述、稀有度、媒体或阶段变化不计为新增实体。
- [x] 页面展示新增实体总数，以及英雄、皮肤、皮肤系列和皮肤宇宙的分类数量、稳定排序和独立空状态。
- [x] 新增英雄展示名称和头像；新增皮肤展示名称、缩略图、本地化稀有度和所属英雄；新增系列展示名称；新增宇宙展示名称与所含系列。
- [x] 新皮肤实体的有效阶段展开为多个皮肤资料项；已有皮肤新增阶段不计为新实体。所有实体链接进入同语言 PBE 详情并保留必要参数。
- [x] 任一必要比较集合失败时不提交部分差集或误导性数量，页面显示可重试错误；常规测试与静态构建不访问真实 CommunityDragon。
- [ ] 自动化与浏览器验收覆盖版本、四类差集、字段变化、阶段口径、数量、空状态、失败重试、本地化隔离、详情导航、键盘和移动端。（按用户要求暂跳过）
