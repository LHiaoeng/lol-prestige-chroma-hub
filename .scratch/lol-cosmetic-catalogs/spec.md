# 英雄联盟外观目录

## 目标与范围

访客可以在四个独立目录中查找已有外观、浏览 PBE 新增并分享筛选结果。每页提供中英文版本，从「英雄联盟」导航下拉进入。沿用[术语表](../../GLOSSARY.md)中的分类名称。

| 中文 | 英文 | 英文路径 | 资料 | 额外筛选 |
| --- | --- | --- | --- | --- |
| 召唤师图标 | Summoner Icons | `/summoner-icons/` | `summoner-icons.json` | 发行年份 |
| 表情 | Emotes | `/emotes/` | `summoner-emotes.json` | 关联英雄 |
| 守卫皮肤 | Ward Skins | `/ward-skins/` | `ward-skins.json` | |
| 终结特效 | Nexus Finishers | `/nexus-finishers/` | `nexusfinishers.json` | |

中文路径统一加 `/zh-cn` 前缀。静态页面提供本地化标题、描述、canonical 和 alternate，八个目录页面纳入站点地图。预览在当前页打开。本期终结特效的媒体范围为图标。

## 站内页面参照

- **棋盘目录**是主要布局参照。沿用紧凑页头、数量摘要、吸顶筛选栏、移动端紧凑控件和抽屉、响应式卡片网格，以及骨架、空状态和重试组件。四个目录保持同一布局，筛选项随分类变化。
- **小小英雄目录**提供关联筛选、URL 状态恢复和分批网格的交互参照。按实际列数成批显示，手机沿用目录模板的两列布局，末批允许不足一行。
- **PBE 新增页**提供这四类外观的字段、图片与 ID 判定参照。沿用现有数据处理和媒体 URL 转换逻辑。
- 具体组件与样式优先复用现有实现，遵循[页面模板](../../docs/page-templates.md)和[前端规范](../../docs/frontend-design.md)。

## 数据、筛选与预览

- 浏览器按当前页面语言和版本请求当前分类。默认展示完整 PBE 数据，从正式服资料经导航进入时继承正式服版本。「仅看 PBE 新增」独立于版本切换，开启后比较同语言的 PBE 和正式服 ID。已有条目的字段变动不计入新增。
- 所有目录支持名称搜索。新旧排序使用物品 ID，默认从新到旧，可切换从旧到新。同名且 ID 不同的条目分别显示。年份缺失的召唤师图标可在「全部年份」中找到。
- 搜索、分类筛选、「PBE 新增」和排序写入 URL。直接访问、分享链接和浏览器前进或后退时恢复条件。切换语言时保留「PBE 新增」、排序和可对应的分类筛选，清空名称搜索。
- 卡片显示图片和名称。参考小小英雄目录，图片打开共享大图查看器，右上角详情按钮打开同页 Popover。召唤师图标显示已有的发行年份和描述，守卫皮肤显示已有描述，表情显示已有的关联英雄，终结特效的媒体为图标。缺失的可选字段省略，图片失败时保留名称和详情并显示占位图。
- 摘要行复用运行时目录的版本下拉、竖分隔线、数量和加载骨架。「仅看 PBE 新增」在 PBE 版本下可用。品质按客户端收藏规则显示，卡片参考皮肤目录在底部居中展示宝石，预览展示品质名称。
- 关闭预览后保留浏览位置，键盘焦点回到触发卡片。筛选栏在无结果时仍可操作。
- 筛选控件优先排成一行，空间不足时换行。手机保持紧凑的搜索与筛选入口，附加控件放入底部抽屉。
- PBE 独有条目的卡片和详情浮层显示「PBE」标签，完整 PBE 列表中排在其他条目前面，两组各自按选择的新旧顺序排列。正式服对照请求失败时，完整 PBE 列表仍可浏览，并提供对照重试。
- 分别展示「本期暂无新增」「当前筛选无匹配」和「数据加载失败」。对应操作为恢复完整 PBE 列表、清除搜索及分类筛选、重试请求。

## 验收

- 相邻测试覆盖同语言 ID 差集、同名条目、缺失字段、搜索与分类筛选组合、URL 状态恢复和语言切换。
- 核对八条路由、导航、双语 SEO 和站点地图。用中英文桌面与手机检查布局、滚动加载、键盘预览、返回位置、骨架、空状态及重试。
- 实现后运行相关测试和文档检查，更新受影响的页面及数据说明。

## 验证结果

四个目录已实现。107 项定向测试与八条双语路由的静态构建测试通过，构建产物审计通过。全量发布检查中的 16 项失败均在本次改动前的提交复现。桌面与手机的实页布局和交互尚未通过浏览器验收。
