# 臻彩原画列表页与首页新增臻彩

## 问题与目标

首页目前同时展示最新博客、资料导航和完整臻彩原画图鉴。把完整图鉴放到独立页面，让首页直接展示本期新增臻彩，同时保留查找历史条目的入口。

## 已确认的方案

| 页面 | 路径 | 行为 |
| --- | --- | --- |
| 首页 | `/`、`/zh-cn/` | 保留最新博客、资料导航、现有页面背景和站点布局。臻彩区直接渲染所有 `isNew: true` 的条目，沿用图鉴默认顺序。 |
| 臻彩原画 | `/prestige-chromas/`、`/zh-cn/prestige-chromas/` | 承接完整目录、搜索、筛选、排序。首批按当前网格列数展示完整行，后续随滚动自动追加。默认包含所有新增状态的条目。 |
| 臻彩详情 | `/chromas/[slug]/`、`/zh-cn/chromas/[slug]/` | 延用现有详情地址，页面面包屑及对应结构化数据中的图鉴项指向同语言的完整图鉴。 |

- 首页臻彩区以主题金色大号按钮提供「查看全部臻彩」或「View all Prestige Chromas」入口，指向同语言的完整列表页。
- 「什么是臻彩」说明显示在列表标题后、筛选前，可使用现有 Alert 关闭按钮隐藏，关闭只作用于当前页面浏览期间；包含原有双语说明及文章入口。
- 旧首页图鉴链接停止兼容。移除 `#prestige-chroma-gallery` 锚点。旧首页查询参数由首页忽略，不迁移筛选或分页状态，也不跳转。站内原本指向该锚点的图鉴入口更新为对应语言的独立图鉴地址。
- 无新增条目时显示「本期暂无新增臻彩」或「No new Prestige Chromas this release.」，继续提供完整图鉴入口。
- 「新增」沿用现有图鉴的来源标记。同一版本中未标记为新增的条目不在首页卡片区出现。即使新增条目超过 24 款，首页也一次展示全部。
- URL 使用术语表中「臻彩」的英文 `Prestige Chroma` 的复数形式。面向访客的板块名称统一为「臻彩原画」和 `Prestige Chroma Splash Art`，适用于页面标题、导航、面包屑、SEO，以及站内介绍同一板块的现有文案。

## 用户故事

- 作为访客，我打开首页即可看到本期新增的所有臻彩，并能进入任一卡片对应的详情。
- 作为查找历史条目的访客，我能从首页进入本语言的完整图鉴，搜索、筛选、排序，并在向下浏览时自动看到更多结果。
- 作为从外部链接进入臻彩详情的访客，我能用面包屑返回本语言的完整图鉴。

## 独立列表页

1. **页头与数量。** 依次显示面包屑、臻彩图标和「臻彩原画」标题、命中数量、分隔线。数量统计所有匹配条目，筛选后更新。例如共有 37 条命中、已展示 24 张时，页头显示 37。所属版本作为条目筛选项。
2. **筛选与结果。** 迁移中英文名称搜索、英雄、所属版本、臻彩分类和新增状态筛选，以及推荐正序／倒序、皮肤 ID 升序／降序和版本降序。保留应用、清除和无结果提示。默认显示所有新增状态的条目，按现有推荐顺序。桌面沿用原画网格，手机端首页和列表页均采用每行两张卡片的网格，筛选默认折叠。
3. **全站入口。** Header 的「英雄联盟」下拉菜单第二项为「臻彩原画」或 `Prestige Chroma Splash Art`，指向同语言列表页。首页保留已确认的「查看全部臻彩」大号按钮入口。
4. **滚动追加。** 接近列表末尾时自动追加下一批，沿用同一排序。首批和后续批次按当前网格列数展示完整行，最后一批展示所有剩余条目。可参考 [Antdv Next Listy 的无限滚动示例](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/docs/src/pages/components/listy/demo/infinite.vue) 的接近末尾触发逻辑，页面仍采用已确认的响应式卡片网格。应用、清除或恢复一组筛选和排序条件时从首批开始。URL 保留搜索、筛选和排序状态。

   - **批量规则。** 首批和后续批次各最多 24 张，按当前列数向下取整到完整行。例如手机两列每批 24 张，桌面五列每批 20 张。
   - **触发位置。** 网格底部进入视口底边下方 200 像素的范围时自动追加。首批未撑满视口时也自动续载，直到网格底部离开触发范围或结果全部显示。
   - **列数变化。** 横竖屏切换或窗口缩放后，已展示的卡片继续可见。下一批按新列数追加，优先补齐当前行，本批总追加量仍最多 24 张。

## 实现与验收

- 复用构建时读取的臻彩目录及现有卡片。首页直接输出新增卡片，完整图鉴承接原有裁剪后的浏览器数据和交互。数据契约、导入流程和详情 URL 沿用现状。
- 完整图鉴使用本站列表页骨架与双语文案，提供页面标题、面包屑、语言切换、canonical 和 hreflang，并加入 sitemap。
- 构建测试核对两种语言首页输出的卡片与全部 `isNew: true` 条目一致，顺序稳定，且首页无完整图鉴数据和操作控件。覆盖零新增和超过 24 款的边界。
- 核对完整图鉴含新增及历史条目，搜索、筛选、排序及 URL 状态恢复可用。验证接近列表末尾时自动追加、每批按列数补齐整行、追加无重复、剩余不足一行时仍全部显示、结果耗尽停止加载，以及筛选后回到首批。检查双语首页入口、详情面包屑和 SEO 指向。
- 核对打开带旧图鉴查询参数和锚点的首页 URL 时仍显示首页新增卡片，站内图鉴链接均可到达独立图鉴。
- 在中英文桌面和手机实页检查卡片、入口和筛选控件的布局，确认手机列表页每行两张卡片，并核对键盘操作、命中数量和各入口的板块名称。实施后运行相关测试及 `pnpm release:build`。
