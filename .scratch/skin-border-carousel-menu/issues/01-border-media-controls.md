# 皮肤列表与详情边框控件

Status: completed

## 范围

实现父规格中的完整边框展示需求。保留皮肤目录现有切换行为，并将皮肤详情轮播中分开的边框控件改为共享 Select，保留在原轮播 Radio.Button 控制组内。

## 验收标准

- 目录卡片保留单卡及批量带框／原图切换、正确的带框数量与半选状态、优先使用预合成带框载入图，以及透明图层回退。
- 有边框媒体时，详情轮播在原有 Radio.Button 控制组内显示“边框”Select；初始无选项，每张透明边框素材与官方带框载入图分别对应一个选项及相册媒体项。
- 选择任一边框选项后立即显示对应轮播画面，透明边框叠加载入图预览。
- 轮播选择、边框预览、全屏相册状态和下载目标保持同步。
- 键盘和触屏均可操作；仅显示一个边框 Select，全部素材选项都在其弹层中并保持在视口范围内。
- 中文和英文标签符合当前语言；缺少的媒体不留下空控件。

## 依赖

无。皮肤目录行为已存在，并由当前浏览器 DOM 测试边界覆盖。

## 验证

透明边框轮播与 Select 的定向 DOM 测试通过（3 项）。`pnpm typecheck` 仍报告其他文件的 10 项既有错误；本次修改文件没有类型错误。真实浏览器中的相册布局和窄屏交互待人工验收。

## 实施结果

- 保留目录卡片单卡与批量边框切换；详情媒体轮播用共享 Select 选择预合成带框载入图或单张透明边框素材，初始不选中边框。
- 多张透明边框分别进入轮播和全屏相册；轮播叠加载入图预览，下载只保存所选透明边框原文件。
- Select 复用现有触屏、键盘和中英文标签行为；窄屏弹层限制在视口内。轮播、全屏预览与当前下载内容同步；失败的边框媒体显示状态并禁用其下载。
- 更新 `docs/page-templates.md`，说明轮播按钮组内的边框 Select 及独立全屏媒体项。

此前实现曾通过详情 DOM 菜单、目录批量边框模式和边框数据测试，并完成中英文、键盘及 320px 窄屏人工核对。本次独立素材调整的定向 DOM 测试通过；实际相册画面仍需复核。
