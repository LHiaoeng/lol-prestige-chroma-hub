# 皮肤列表与详情边框控件

Status: completed

## 范围

实现父规格中的完整边框展示需求。保留皮肤目录现有切换行为，并将皮肤详情轮播中分开的边框控件改为共享 Select，保留在原轮播 Radio.Button 控制组内。

## 验收标准

- 目录卡片保留单卡及批量带框／原图切换、正确的带框数量与半选状态、优先使用预合成带框载入图，以及透明图层回退。
- 有边框媒体时，详情轮播在原有 Radio.Button 控制组内显示“边框”Select；选项列出可用的预合成带框载入图和透明边框图，多款透明边框通过同一控制组内的图层二级 Select 选择。
- 同层变体互斥，不同图层同时合成，固定图层保持包含。
- 轮播选择、边框预览、全屏相册状态和下载目标保持同步。
- 键盘和触屏均可操作；一级和二级 Select 均保持在轮播按钮组内，弹层保持在视口范围内。
- 中文和英文标签符合当前语言；缺少的媒体不留下空控件。

## 依赖

无。皮肤目录行为已存在，并由当前浏览器 DOM 测试边界覆盖。

## 验证

原始实现使用运行时详情 DOM 与皮肤目录 DOM 测试验证。此次边框控件改为 Select 后尚未运行测试与类型检查，留待用户验收。

## 实施结果

- 保留目录卡片单卡与批量边框切换；详情媒体轮播用共享 Select 选择预合成带框载入图和透明边框图，控件及图层二级 Select 均位于原轮播 Radio.Button 按钮组内。透明边框有多个款式时按图层分组显示二级选项，固定图层自动保留。
- Select 复用现有触屏、键盘和中英文标签行为；窄屏弹层限制在视口内。轮播、全屏预览与当前下载内容同步；失败的边框媒体显示状态并禁用其下载。
- 更新 `docs/page-templates.md`，说明轮播按钮组内的边框 Select 及独立全屏媒体项。

验证：详情 DOM 菜单测试、目录批量边框模式测试和边框数据测试通过；真实页面验证英文、中文、键盘和 320px 窄屏。独立提交快照的相关测试共 90 项通过；`pnpm typecheck` 与 HEAD 基线均报告相同的 13 个既有错误。
