# 皮肤目录边框切换与详情轮播边框 Select

## Problem Statement

访客在皮肤目录需要快速比较带框与原始载入图，在皮肤详情需要查看官方带框成品和可选的透明边框素材。两处必须正确区分预合成载入图与透明边框图层。当前详情轮播把两种边框媒体分别放在控制条中，透明边框变体又在画面内用按钮选择；访客需要在拥挤的控制条和画面之间寻找边框内容，手机上尤其不便。

## Solution

皮肤目录卡片保持带框／原图单卡切换与工具栏批量切换：优先显示来源提供的带边框载入图；没有成品图时，在原始载入图上叠加各层默认边框。详情轮播控制条只提供一个“边框”Select，初始不选中边框。来源提供的带框载入图与每张透明边框素材分别列为选项；选择后立即切换到对应轮播项。透明边框在轮播中叠加载入图，在全屏相册中分别显示原素材，下载对应透明边框原文件。原始载入图继续作为独立媒体选项。

## User Stories

1. 作为访客，我希望在轮播控制条看到一个“边框”入口，以便集中查找该皮肤的边框媒体。
2. 作为访客，我希望原始载入图仍能单独选择，以便与带框画面比较。
3. 作为访客，我希望在来源提供官方带边框载入图时直接从边框 Select 打开它，以便查看来源的完整成品。
4. 作为访客，我希望在来源提供透明边框图层时从同一 Select 打开边框图，以便查看独立素材。
5. 作为访客，我希望 Select 只列出当前数据通道和本地化视图实际提供的媒体，以便不会点到空项。
6. 作为访客，我希望两种边框媒体同时存在时都能分别选择，以便不会丢失其中一种来源。
7. 作为访客，我希望边框 Select 初始不选中任何边框，以便当前普通媒体与控件状态一致。
8. 作为访客，我希望每张透明边框素材都是同一个 Select 中的独立选项，以便直接选择具体款式。
9. 作为访客，我希望选择任一透明边框后立即显示对应轮播画面，以便准确比较。
10. 作为访客，我希望多个透明边框在全屏相册中分别显示，以便逐张查看原素材。
11. 作为访客，我希望 Select 选项标出素材的图层和款式，以便区分相近边框。
12. 作为访客，我希望只有一张透明边框素材时也能直接选择它，以便控制方式一致。
13. 作为访客，我希望查看普通媒体时边框 Select 重新为空，以便当前选择明确。
14. 作为访客，我希望轮播在载入图上叠加当前透明边框变体，以便直接确认成品外观。
15. 作为访客，我希望返回普通媒体时边框 Select 清空，再次选中某张透明边框时立即显示该素材，以便明确当前画面。
16. 作为访客，我希望进入全屏相册时逐张看到透明边框原素材，以便放大检查细节。
17. 作为访客，我希望从全屏相册返回后轮播和边框 Select 指向最后查看的媒体，以便不会失去位置。
18. 作为访客，我希望下载官方带边框载入图时得到来源原文件，以便保存完整画面。
19. 作为访客，我希望下载透明边框图时得到当前所选素材的原文件，以便单独保存该边框。
20. 作为中文访客，我希望 Select 和边框变体使用中文标签，以便理解选项。
21. 作为英文访客，我希望 Select 和边框变体使用英文标签，以便理解选项。
22. 作为手机访客，我希望通过一个 Select 弹层操作边框媒体和图层变体，并能在窄屏完整使用。
23. 作为键盘用户，我希望能使用键盘操作 Select 并看见焦点，以便完整操作边框媒体。
24. 作为使用辅助技术的访客，我希望理解 Select 的当前选中项和展开状态，以便理解选择结果。
25. 作为访客，我希望边框资源加载失败时看到明确的失败或回退状态，以便不会把缺图误认为无边框。
26. 作为访客，我希望切换 PBE 与正式服／Live 后 Select 选项反映目标通道的实际媒体，以便不会保留已不存在的边框选项。
27. 作为皮肤目录访客，我希望可用边框的卡片默认显示带框载入图，以便快速识别完整外观。
28. 作为皮肤目录访客，我希望单独切换一张卡片的带框／原图，以便比较同一皮肤的两种画面。
29. 作为皮肤目录访客，我希望用工具栏的“边框”复选框批量切换可用卡片，以便统一比较当前结果。
30. 作为皮肤目录访客，我希望单卡选择与批量设置不一致时看到半选状态，以便理解当前混合显示情况。
31. 作为皮肤目录访客，我希望看到带框卡片数与可切换卡片总数，以便理解批量开关的作用范围。
32. 作为皮肤目录访客，我希望有官方带框载入图时优先看到来源成品，以便保留官方画面效果。
33. 作为皮肤目录访客，我希望没有官方成品但有透明边框图层时看到原始载入图与各层默认边框的组合，以便仍能预览带框效果。
34. 作为皮肤目录访客，我希望无可用边框的卡片不出现切换按钮，也不计入批量统计，以便控件只对应实际可切换内容。
35. 作为皮肤目录访客，我希望没有可切换皮肤时不显示批量边框开关，以便工具栏没有空操作。
36. 作为皮肤目录访客，我希望切换卡片／时间轴视图后保持相同的卡片边框选择，以便不因浏览方式改变比较结果。
37. 作为手机访客，我希望单卡切换按钮始终可见且可点击，以便不用依赖悬停。
38. 作为键盘或辅助技术用户，我希望单卡按钮和批量开关说明当前状态，以便能独立完成比较。
39. 作为皮肤目录访客，我希望来源图片加载失败时看到正确的回退或缺图状态，以便不会把无效图片当作带框效果。

## Implementation Decisions

- 保持 Astro 静态站与浏览器运行时资料架构。已核对 [Antdv Next Select 实现](https://github.com/antdv-next/antdv-next/blob/main/packages/antdv-next/src/select/index.tsx)、[Select 样式](https://github.com/antdv-next/antdv-next/tree/main/packages/antdv-next/src/select/style) 与 [`@v-c/select` 基础实现](https://github.com/antdv-next/vue-components/tree/next/packages/select/src)；本地通用 Select 按上游默认主题还原单选框、选项、弹层、尺寸与状态样式，并用隐藏原生 `<select>` 兼容现有值与 `change` 事件，不引入 Vue。
- 边框素材直接使用共享 Select 的普通选项；每个选项对应一个媒体项，初始无选中项。
- 皮肤目录卡片保留现有单卡与批量带框／原图切换，卡片和时间轴视图共用同一规则及状态。默认带框；单卡覆盖全局设置后，批量复选框按全部、部分、无三种状态反馈，并显示带框数／可切换总数。
- 目录卡片有官方预合成带框载入图时优先使用该图；否则使用原始载入图并按图层顺序叠加各层最高优先级边框。目录只切换最终带框效果与原图，不提供边框变体 Select。缺少原始载入图或两类边框来源时不提供虚假的可切换状态；无可切换皮肤时隐藏批量开关。
- 轮播继续按媒体项管理原始载入图、官方带边框载入图和透明边框图；仅把后两者的控制条入口归入共享 Select 的一个“边框”下拉。每张透明边框素材各占一个轮播及全屏相册项。
- 仅在至少有一种可用边框媒体时显示“边框”下拉。选项列出来源提供的官方带边框载入图和每张透明边框图；缺少的来源不显示。两种来源同时存在时分别保留。
- Select 为每张透明边框素材提供独立选项，选项名称包含图层和款式。初始以及查看普通媒体时不选中边框；选中选项时立即切换到对应媒体。
- 透明边框轮播画面以原始载入图为底叠加当前选中的一张素材；载入图缺失时仍显示透明边框。全屏相册分别显示透明素材原图，关闭相册后轮播与 Select 同步到最后查看的媒体。
- 官方成品与透明边框分别下载来源原文件；透明边框下载不包含载入图。
- 复用当前运行时资料的通道和本地化视图，不通过边框道具目录推断皮肤与边框关系，不改数据契约或持久化选择。
- 边框 Select 留在轮播现有 Radio.Button 控制组内，素材选项沿用共享 Select 的鼠标、键盘、触屏及辅助技术行为。窄屏控件铺满可用宽度，不导致页面横向溢出。
- 页面文案、响应式样式和相关展示规范同步更新；保留原有轮播尺寸、下载入口及其他媒体交互。

## Testing Decisions

- 主要测试 seam 是皮肤详情的高层 DOM 行为：用固定媒体数据渲染详情、操作轮播与 Select，断言访客可见的 Select 选项及选中状态、媒体画面和下载目标。沿用现有运行时详情 DOM 测试先例，不为菜单内部辅助函数另建重复测试。
- 皮肤目录沿用现有目录浏览器行为测试 seam：用固定皮肤数据操作批量开关、单卡按钮和卡片／时间轴视图，断言可见图片、按钮状态、半选状态与统计，不测试内部状态容器。
- 目录测试覆盖官方带框图优先、透明图层默认组合、无边框、缺少载入图、图片失败，以及批量与单卡选择的相互作用；核对中英文与当前数据通道的可用项。
- 在同一 seam 覆盖无边框、仅官方成品、仅透明边框、两者同时存在，以及单款、多变体、多图层的组合；验证初始无选项、每张透明素材独立呈现以及选择后立即切换。
- 验证通过轮播与全屏相册选择边框后双方状态同步，透明边框轮播叠加载入图，相册与下载使用所选素材原文件；失败资源不留下可操作的空选项。
- 验证中英文标签、点击与键盘操作、选中与展开语义；断言现有调用方可观察的选择值、媒体及下载行为，并检查 Select DOM/样式与上游结构规则一致。现有边框分组及优先级领域测试继续作为数据规则的先例。
- 实施时先运行相关 Vitest 测试和类型检查；真实页面核对中英文、桌面、手机、列表卡片／时间轴、十档段位、视口边缘、全屏相册及下载。

## Out of Scope

- 不在皮肤目录卡片增加边框变体选择；目录的批量／单卡切换继续按现有交互工作。
- 不新增边框道具目录、数据源、字段或服务器 API。
- 不把透明边框图层烘焙进原始载入图，也不把官方带边框载入图拆分成透明素材。
- 不重做其他媒体的轮播、全屏相册或下载交互，不引入 Vue 组件运行时。
- 不持久化边框变体到 URL 或跨会话存储。

## Further Notes

- 皮肤边框与边框变体采用项目领域词义；边框是载入画面的视觉元素，边框变体是同层互斥款式。来源与四种字段组合见现有皮肤边框数据源调研。
- 当前工作区已有皮肤目录边框切换、皮肤详情轮播、透明边框图层选择和共享 Select；实施应在这些边界上调整，不替换用户正在进行的其他改动。
