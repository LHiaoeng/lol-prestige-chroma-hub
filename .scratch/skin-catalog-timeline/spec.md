# 皮肤目录卡片与时间轴模式切换

## Problem Statement

现有皮肤目录只用竖版卡片展示皮肤。访客可以按发布时间排序，却难以连续浏览日期与同日上线记录，也无法区分中文页回退使用的直营服日期与国服日期。新增时间轴模式，让日期成为浏览结构，同时保留卡片模式的原画浏览体验。

## Solution

在 `/skins/` 与 `/zh-cn/skins/` 的结果工具栏加入“卡片 / 时间轴”双选项，默认时间轴。两种模式使用同一份运行时皮肤目录、现有搜索与筛选条件；时间轴按日期分组，以 Antdv Next 1.6.0 的左侧竖向 Timeline 为结构和视觉基准，在同日节点内展示与卡片模式完全一致、由同一渲染器生成的皮肤卡片。仅卡片模式写入 `view=cards`，可通过链接和浏览器前进、后退恢复。

## User Stories

1. 作为访客，我希望在卡片与时间轴之间切换，并保留搜索、稀有度、经典皮肤、PBE 新增和数据通道状态，以便从不同角度浏览同一结果。
2. 作为访客，我希望按日期阅读皮肤上线记录，同一天的皮肤出现在同一个节点，以便看清发布节奏。
3. 作为中文访客，我希望看出日期属于国服还是回退采用的直营服资料，以免把两者误读为同一次上线。
4. 作为访客，我希望 PBE 新增固定在时间轴顶部，其他无确切日期的皮肤仍可在末尾找到，以免推断不存在的日期。
5. 作为手机、键盘或辅助技术用户，我希望时间轴条目和模式切换均可阅读、聚焦与操作。

## Scope and Data Decisions

- **同一目录范围**：复用皮肤目录现有投影，排除英雄默认外观；有效皮肤阶段继续作为独立资料项与详情链接。阶段使用所属皮肤 `skinId` 的日期，不产生独立发布时间。结果数量在两种模式下相同。
- **日期来源**：只读现有 `data/skin-release-dates.json` 仓库快照，以 `skinId` 关联当前 CommunityDragon 通道与本地化视图的皮肤；不在浏览器请求 Wiki，也不从名称、皮肤 ID 顺序或阶段推算日期。英文使用 `globalReleaseDate`，并标为 League of Legends Wiki 发布时间；中文优先 `chinaReleaseDate`，无值时采用 `globalReleaseDate`，在每个受影响条目明确标为直营服参考日期。没有任何确切日期时进入“日期待确认”组。日期分组使用原始 `YYYY-MM-DD` 日历日，不做时区换算。
- **已知数据现状**：当前日期快照包含 2127 款正式服皮肤；2127 条有直营服日期，1040 条有国服日期。因此中文时间轴有大量回退条目，来源标签不可只放在组标题。快照覆盖率会随维护更新，界面规则不依赖这些数量。
- **PBE 新增**：沿用当前通道内按数字皮肤 ID 与 `latest` 比较的判定。所有已确认的 PBE 新增，无论日期快照是否有值，均固定在顶部“PBE 新增”专组；组内不显示日期，也不把该组算作某一日的发布记录。未能完成差集判定时不擅自标记为新增。非 PBE 的无日期资料项位于末尾“日期待确认”组；两组仅在有匹配结果时出现。
- **排序**：时间轴仅提供“发布时间：最新优先 / 最早优先”；PBE 组始终最前，未知日期组始终最后。已知日期按所选方向排序；同日和特殊组内沿用现有英雄 ID、皮肤与阶段的稳定顺序。从卡片模式的英雄名称排序切入时间轴时，改为最新优先；切回卡片模式可重新选择英雄名称排序。

## Interface and Interaction Decisions

- **模式切换**：在现有结果工具栏使用本站已有 Antdv Next 风格双选项控件，文案为“卡片 / 时间轴”与“Cards / Timeline”。默认时间轴；仅卡片模式写入 `view=cards`，未知 `view` 值回退时间轴。模式、排序及既有 URL 参数共同决定可分享状态；切换模式保留当前搜索、稀有度、仅看经典皮肤、PBE 新增及通道选择，重新展示首批结果并把视口定位到结果区顶部。模式切换不触发重新下载已就绪的完整皮肤集合。
- **时间结构**：按所选方向使用一条连续的有序 Timeline 列表；每个确定日期只有一个节点，轨迹固定在版心最左侧。宽屏时版本标题绝对定位在节点左侧、版心之外并与圆点对齐，不为标题预留布局列；标题采用上游的正文大小、常规字重及右对齐，保留本站主题色。日期在轨迹右侧的内容起始处显示，当天皮肤卡片位于日期下方。缺少版本号时留空，不按日期推算；同日皮肤版本均已确认但存在多个版本时逐一显示。无日期节点右侧显示“日期待确认”。PBE 新增仍固定在顶部，左侧标题留空，右侧标题显示“PBE 新增”，不显示上线日期。筛选后只保留有结果的节点。
- **节点内容**：复用皮肤目录卡片模式的同一皮肤卡片渲染器与响应式网格，包含载入图、底部名称、皮肤徽章、稀有度与卡片操作。日期来源在卡片详情弹层中显示，英雄详情链接也在该弹层中提供。
- **外观偏好**：卡片模式与时间轴共用皮肤卡片外观、全局皮肤徽章／边框开关及单卡边框切换；卡片状态仍由现有目录逻辑管理。
- **分批加载**：沿用手动“加载更多”，每批以约 50 个皮肤资料项为目标。若边界落在同一个日期节点内，则把该日期余下条目一并展示；PBE 和未知日期专组同样保持完整，不拆成两个同名节点。按钮仅在仍有未展示节点时出现。命中数表示全部匹配资料项数，不随已加载批次改变。
- **加载与失败**：沿用现有页面的骨架、空结果、错误、重试及通道切换时保留已就绪结果的规则；时间轴骨架沿用卡片模式的载入图比例，不额外显示“正在加载皮肤资料…”文案。皮肤载入图失败时沿用卡片模式的回退图片与缺图占位行为。

## Design and Accessibility Contract

- **上游基准**：按 [Antdv Next 1.6.0 Timeline 主体源码](https://github.com/antdv-next/antdv-next/blob/antdv-next@1.6.0/packages/antdv-next/src/timeline/Timeline.tsx)、[节点投影源码](https://github.com/antdv-next/antdv-next/blob/antdv-next@1.6.0/packages/antdv-next/src/timeline/useItems.tsx)、[「标题」示例源码](https://github.com/antdv-next/antdv-next/blob/antdv-next@1.6.0/docs/src/pages/components/timeline/demo/title.vue)、[Timeline 样式源码](https://github.com/antdv-next/antdv-next/blob/antdv-next@1.6.0/packages/antdv-next/src/timeline/style/index.ts)及其依赖的 [Steps 结构源码](https://github.com/antdv-next/antdv-next/blob/antdv-next@1.6.0/packages/antdv-next/src/steps/index.tsx)和 [Steps 样式源码](https://github.com/antdv-next/antdv-next/blob/antdv-next@1.6.0/packages/antdv-next/src/steps/style/index.ts)复刻竖向轨迹、圆点、标题/内容布局、间距与状态。仅把颜色、字体和基础间距映射到 `DESIGN.md` 与本站 Token；不引入 Vue 运行时。若复制上游代码，按仓库现有组件方式保存对应 MIT 许可。
- **响应式**：各宽度下轨迹均贴版心左边界，日期和卡片在轨迹右侧；版心外侧不足以容纳版本标题时，标题改在右侧内容上方显示，避免裁切或横向溢出。卡片网格沿用目录卡片模式的列数、间距和 11:20 载入图卡片布局。320px 视口无横向溢出；皮肤名称与操作沿用卡片模式的显示和聚焦行为。
- **语义与状态**：Timeline 主序列使用一条连续有序列表及列表项；每个节点标题使用 `h2`，真实日期用 `<time datetime="YYYY-MM-DD">`。特殊节点不伪装成有日期的 `<time>`。模式控件有可读名称与选中状态；图片、稀有度、徽章及 PBE 标记有等价文字；链接有可见键盘焦点。加载更多后维持合理焦点顺序；减少动态效果时不依赖动画表达状态。

## Testing and Acceptance Decisions

- 领域测试覆盖同日分组、日期方向、中文回退来源、阶段继承父皮肤日期、PBE 顶部专组、未知日期末尾，以及批次在同日边界处扩展。
- 客户端行为测试覆盖默认时间轴、`view=cards` 直达、无效模式回退、浏览器前进后退、筛选条件保持、从英雄排序切换时重置为最新优先、模式切换不重复请求、加载更多与各类空/失败状态。
- 实际页面核对中英文、`latest`/`pbe`、桌面与 320px 手机、长名称、同日多款、图片失败、键盘焦点和触屏；将 Timeline 轨迹、圆点、标题/内容及间距与固定上游源码对应的样式逐项比对。

## Out of Scope

- 不改动卡片模式的既有卡片视觉和详情页，不新增独立时间轴路由或新的远程数据源。
- 不把英雄默认外观纳入皮肤目录，不为阶段、PBE 或未知日期编造发布时间。
- 不新增账号、拥有状态、自动无限滚动或虚拟列表。
