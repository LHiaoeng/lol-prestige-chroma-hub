# 02: 双语棋盘目录入口与页面壳

**What to build:** 访客能从页头的云顶之弈入口进入英文 Arenas 或中文棋盘目录，并获得符合本站双语 SEO、面包屑与隐私说明的静态页面壳。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] `/tft/arenas/` 与 `/zh-cn/tft/arenas/` 显示各自的标题、领域图标、面包屑和 JavaScript 启用提示。
- [ ] 页头云顶之弈入口提供小小英雄与棋盘两个同级导航链接，键盘和触控均可操作。
- [ ] 页面提供双语 canonical、`hreflang`、CollectionPage 与 BreadcrumbList 结构化数据，并列入 sitemap。
- [ ] 中英文隐私说明与 README、CommunityDragon 资源指南描述浏览器直连 `tftmapskins.json` 和媒体。
