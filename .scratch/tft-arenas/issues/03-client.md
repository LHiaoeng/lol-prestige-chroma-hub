# 03: 棋盘目录运行时浏览

**What to build:** 访客能在双语棋盘目录中切换 PBE／正式服，搜索、筛选、排序、预览和分批浏览数据；分享或恢复链接时保留状态，局部资料失败不影响主列表。

**Blocked by:** 01-domain.md, 02-page.md.

**Status:** in-progress

- [x] 按页面语言和通道直接读取 CommunityDragon `tftmapskins.json`，正式服比较或另一语言失败时保留主列表并提供单独重试。
- [x] 通道、搜索、分组、等级、排序与 PBE 新增筛选可从 URL 恢复，并支持刷新、前进与后退；非法参数回到安全默认值。
- [x] 切换通道成功后才更新 URL 和结果；失败保留原结果和地址，迟到响应不覆盖新状态。
- [x] 每批最多新增 50 张并按网格完整行取整；搜索或筛选变化回到首批，调整窗口宽度保留已加载行数。
- [x] 卡片显示当前视图名称与等级，方形封面可键盘或触控打开共享媒体预览；缺图时保留名称和等比占位。
- [ ] 首次加载、主资料空/失败、无匹配和局部资料失败均有清楚状态；双语桌面与 320px 页面无横向溢出并支持减少动态效果。静态结构与 CSS 已实现；桌面、320px、键盘和预览的真实浏览器验收待补。浏览器 UI 工具自动审核无法确定目标 URL，本轮未能执行浏览器操作。
