# PRD：云顶之弈棋盘目录

## 问题与目标

新增独立的云顶之弈棋盘外观列表页，供访客按名称、分组和外观等级浏览当前 CommunityDragon 资料。英文类别名使用 Riot 官方的 **Arenas**，中文使用本站术语表中的“棋盘”。实现按本目录下的实施工单推进。

## 数据依据与口径

- 浏览器按页面语言和数据通道读取 CommunityDragon `tftmapskins.json`；英文使用 `default`，简体中文使用 `zh_cn`，通道沿用 `pbe` 与 `latest`。
- 收录来源中所有可独立识别的棋盘外观，包括 `groupId=0` 的 Base 棋盘；同名条目不按名称或图片合并。
- 以 `itemId` 区分条目，以 `groupId` 区分分组，名称和组名来自当前本地化视图。
- 外观等级使用 `TFTRarity`。来源 `rarity` 与它并不总一致，不能混用；`IsWIP` 不能用于判定 PBE 新增。
- 来源 `description` 可以为空，不作为条目有效性的必需字段。
- Riot 官方将该外观类别称为 [Arenas](https://teamfighttactics.leagueoflegends.com/en-gb/news/game-updates/simplifying-cosmetics-tiering/)；CommunityDragon 路径与媒体转换遵循 [资源指南](../../docs/CD资源指南.md)。

## 用户故事

1. 访客从云顶之弈导航进入本语言棋盘目录，查看当前数据通道中的全部棋盘，包括基础棋盘。
2. 访客通过中英文名称或组名搜索，并按分组与外观等级缩小结果；分享链接后能恢复同一浏览状态。
3. 访客切换 PBE／正式服，识别仅在 PBE 出现的棋盘，并查看来源原图。
4. 访客在手机、键盘、辅助技术或外部资料部分失败时，仍能理解当前结果和可用操作。

## 页面与交互

- **入口与骨架**：新增 `/tft/arenas/` 与 `/zh-cn/tft/arenas/`；页头“云顶之弈”入口提供“小小英雄”和“棋盘”两个同级导航项。页面使用本站列表页骨架：面包屑、领域图标与标题、数据通道切换和总数、搜索与筛选、命中数、卡片网格。中文标题为“棋盘”，英文标题为“Arenas”。默认通道沿用现行 `pbe`；`channel=latest` 显示正式服／Live。
- **搜索与筛选**：搜索匹配当前语言及另一语言的棋盘 `name` 与 `groupName`，跨语言记录分别按 `itemId`、`groupId` 关联；忽略首尾空白及大小写。卡片只显示当前语言资料，不跨本地化视图补名称或其他事实。以 `groupId`、`TFTRarity` 分别单选筛选，多个条件取交集；“全部”清除对应条件。分组选项取当前响应中的组，标签使用当前视图的 `groupName`，包括 Base 组。默认平铺展示，不增加按组浏览模式。
- **排序**：默认按 `itemId` 从大到小排列；可切换 ID 升序，以及外观等级、当前语言名称的升序或降序。其他排序出现同级或同名时，以 `itemId` 降序固定顺序。PBE 新增项在任意排序和筛选结果中始终置顶，置顶项与其余项各自按所选规则排序。ID 仅用于排序，不据此推断发布日期。
- **卡片**：一条有效 `itemId` 一张卡，以 `loadoutsIcon` 的方形图片为主体；显示当前语言名称和外观等级。封面可点击或用键盘激活，通过共享媒体预览查看原图。信息弹层显示名称、分组和等级，有非空 `description` 时再显示描述；不把缺失描述当作错误，也不展示内部 ID。图片失败时保留文字和等比占位，卡片本身不伪装成详情链接。
- **PBE 比较**：PBE 通道按同一本地化视图的 `itemId` 与 `latest` 比较，提供默认关闭的“PBE 新增”筛选和卡片角标；已有 ID 的名称、等级、图片或描述变化不算新增。正式服对照失败时仍显示 PBE 主列表，隐藏新增筛选与角标，说明比较暂不可用并允许单独重试；不得把全部 PBE 条目误标为新增。
- **状态与 URL**：数据通道、搜索、分组、等级、排序、PBE 新增筛选写入 URL，支持直达、分享、刷新、前进和后退恢复。非法参数给出可恢复提示并回到安全默认值，不允许 URL 指定任意资料源。切换通道时待目标主数据成功后才更新结果和 URL；失败保留原结果和 URL，提供重试；迟到响应不得覆盖新状态。
- **批次**：首批最多展示 50 张卡片，“加载更多”每批追加最多 50 张，并按当前网格列数取整到完整行；最后不足一行时仍全部显示。窗口尺寸变化时保持已加载行数；筛选或搜索变化回到首批。全部展示后隐藏按钮，不使用无限滚动或浏览器持久缓存。
- **加载与异常**：首次加载显示与网格对应的骨架；切换通道并保留旧结果时显示居中的加载状态。当前语言主数据为空、无匹配、请求失败、格式或图片路径不合法时分别显示清晰的 Empty 或 Alert 与重试；主数据格式异常不能用宽松默认值掩盖。另一语言视图失败时保留当前语言列表与本语言搜索，提示跨语言搜索暂不可用并允许单独重试。

## 视觉、无障碍与 SEO

- 复用 `DESIGN.md` 的暗色金色 Token、`BaseLayout`、列表页版心、共享控件与媒体预览。图片以 1:1 展示；卡片网格在手机宽度减少列数，320 CSS px 无页面级横向溢出。尊重减少动态效果设置。
- 搜索、筛选、排序、通道切换、预览、重试和“加载更多”有可见标签、键盘操作与焦点状态；加载、错误、命中数、等级和 PBE 角标有可读文字，不只靠图标或颜色。禁用脚本时仍能看到标题、导航和启用脚本提示。
- 两个静态列表壳提供本地化标题与描述、canonical、`hreflang`、一致的面包屑结构化数据和 sitemap 条目。动态卡片不宣称为已静态索引的实体页；隐私说明覆盖浏览器直连 CommunityDragon 获取棋盘 JSON 与图片。

## 验收标准

1. 固定夹具验证全部有效 `itemId` 独立保留，含 Base 组；重复或非法 ID、未知等级和无效媒体路径报错；`TFTRarity` 与 `rarity` 不一致时以前者为准。
2. 中英文页面按同一 `itemId` 和 `groupId` 对接别名搜索，但卡片事实均来自当前视图；默认结果按 ID 降序，切换 ID 升序、等级或名称排序后，搜索、分组、等级、命中数、列表和 URL 一致。
3. PBE 新增仅按 `itemId` 差集判定并置顶；对照或另一语言视图失败时主列表可用，局部功能清楚降级并可重试；通道切换失败或迟到请求不改变已确认的列表和地址。
4. 首次加载、空集合、无匹配、主数据失败、图片失败、无脚本、键盘、触控、减少动效、桌面和 320 CSS px 手机均验收；每批新增不超过 50 张。
5. 实施阶段同步更新导航、SEO、隐私、README 与受影响文档，补充相邻测试，并运行相关测试、类型检查和发布构建。

## 范围外与边界

- 不新建棋盘详情页、账号藏品管理或购买入口；不推断获取方式、商店价格、持有、在售状态或发布日期。
- 不把 CommunityDragon 完整 JSON 或媒体复制到 `public/`、构建产物或站点数据库；不新增代理。
- 可索引的是双语静态页面壳，卡片内容需浏览器执行 JavaScript 才出现。
