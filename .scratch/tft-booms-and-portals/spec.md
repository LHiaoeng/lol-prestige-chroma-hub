# 云顶之弈进攻特效与传送门目录

## 问题

云顶之弈已有小小英雄与棋盘目录。玩家需要同样的浏览入口来查看进攻特效与传送门，查找特定外观和当期 PBE 新增条目。

## 页面与导航

| 页面 | 英文路由 | 中文路由 |
| --- | --- | --- |
| 进攻特效（Booms） | `/tft/booms/` | `/zh-cn/tft/booms/` |
| 传送门（Portals） | `/tft/portals/` | `/zh-cn/tft/portals/` |

现有 TFT 导航在小小英雄、棋盘之后依次加入进攻特效和传送门。两页以小小英雄目录为页面结构基准，对齐面包屑、标题区、版本切换、筛选区、结果摘要、展示方式和结果网格的布局顺序、间距及响应式行为。沿用现有移动端筛选抽屉和同类页面的 SEO 规则。

卡片沿用小小英雄目录的共享样式，对齐相同断点和展示方式下的图片比例、标题行高、操作区和卡片高度。筛选项按各物品目录的数据提供，功能标签筛选纳入同一筛选区。

功能标签沿用小小英雄目录的多选控件，桌面筛选区和移动端筛选抽屉共用同一筛选状态。

## 浏览与数据规则

- 进攻特效读取 CommunityDragon 的 `tftdamageskins.json`，传送门读取 `tftzoomskins.json`。沿用棋盘目录的浏览器运行时加载规则，默认 PBE，可切换正式服。图片与列表使用同一数据通道。
- 卡片名称使用当前页面语言，搜索同时匹配中英文名称。稀有度筛选使用物品表的 `TFTRarity`。
- 「PBE 新增」与展示方式独立。启用时按同一物品类别的 `itemId` 比较，只展示 PBE 有而正式服缺少的条目。同 ID 的改名、换图或稀有度调整仍属于已有条目。
- 卡片展示名称、静态图与稀有度，缩略图使用 `loadoutsIcon`。点击图片沿用现有看图交互。传送门有 `largeLoadoutsIcon` 时用作大图，未提供时使用普通图。

## 目录内详情与功能标签

- 点击物品名称打开目录内的详情面板，展示静态图、稀有度，以及每个功能标签的图标和当前页面语言的名称。列表卡片沿用已确认的内容，点击图片继续直接看大图。
- 使用物品的 `contentId` 匹配同一数据通道的 `tftcontentdata.json`，再用 `contentData.featureTags[].featureType` 匹配当前语言的 `tftdisplaytags.json` 中对应的 `TFTFeatureDisplayTag`，读取 `icon` 和 `name`。例如 `kEvolvingBoom` 显示其图标和「可进化型进攻特效」。
- 有多个功能标签时逐项展示。没有可展示标签时隐藏该区。补充标签数据加载失败时，仍可查看物品基本资料和图片。
- 两个目录均支持功能标签多选，选项显示图标和当前页面语言的名称。筛选选项取自当前类别和数据通道中实际存在的标签。选中多个标签时，物品命中任意一个即可通过该筛选，再与名称、稀有度和「PBE 新增」条件取交集。当前类别和数据通道没有可选标签时，隐藏该筛选项。

## 首版范围

交付两个目录、导航入口、目录内详情面板及功能标签筛选。独立详情页、动态演示、小小英雄关联、TFT 主题表情与货币页面留待单独讨论。

## 验收

- 验证中英文四个路由及导航入口，检查桌面与手机上的布局、筛选和看图交互。
- 在相同语言、视口和展示方式下，与小小英雄页面并排核对页面结构、筛选区、网格及卡片高度。
- 用相邻测试覆盖两类资源的路径构建、双语搜索、稀有度与 PBE 差集。覆盖同 ID 字段变化、两类物品编号重合、传送门大小图选择。
- 验证展示方式和 PBE 新增可以同时使用。零结果时筛选仍可用。沿用棋盘目录的加载、失败和重试行为。
- 验证详情中功能标签图标与中英文名称同时可见，并覆盖无标签、多标签和标签数据加载失败的情况。
- 验证功能标签选项随类别和数据通道变化，覆盖无可选标签、多选命中任意一项及与其他筛选组合后无结果的情况。
- 更新对应的资源指南，运行相关测试、`git diff --check` 与 `pnpm release:build`。
