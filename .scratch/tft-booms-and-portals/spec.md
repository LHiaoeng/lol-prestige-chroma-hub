# 云顶之弈进攻特效与传送门目录

## 问题

云顶之弈已有小小英雄与棋盘目录。玩家需要同样的浏览入口来查看进攻特效与传送门，查找特定外观和当期 PBE 新增条目。

## 页面与导航

| 页面 | 英文路由 | 中文路由 |
| --- | --- | --- |
| 进攻特效（Booms） | `/tft/booms/` | `/zh-cn/tft/booms/` |
| 传送门（Portals） | `/tft/portals/` | `/zh-cn/tft/portals/` |

现有 TFT 导航在小小英雄、棋盘之后依次加入进攻特效和传送门。页面沿用棋盘目录的布局、响应式与展示方式，以及同类页面的 SEO 规则。

## 浏览与数据规则

- 进攻特效读取 CommunityDragon 的 `tftdamageskins.json`，传送门读取 `tftzoomskins.json`。沿用棋盘目录的浏览器运行时加载规则，默认 PBE，可切换正式服。图片与列表使用同一数据通道。
- 卡片名称使用当前页面语言，搜索同时匹配中英文名称。稀有度筛选使用物品表的 `TFTRarity`。
- 「PBE 新增」与展示方式独立。启用时按同一物品类别的 `itemId` 比较，只展示 PBE 有而正式服缺少的条目。同 ID 的改名、换图或稀有度调整仍属于已有条目。
- 卡片展示名称、静态图与稀有度，缩略图使用 `loadoutsIcon`。点击图片沿用现有看图交互。传送门有 `largeLoadoutsIcon` 时用作大图，未提供时使用普通图。

## 首版范围

交付两个目录及其导航入口。独立详情页、动态演示、物品功能标签、小小英雄关联、TFT 主题表情与货币页面留待单独讨论。

## 验收

- 验证中英文四个路由及导航入口，检查桌面与手机上的布局、筛选和看图交互。
- 用相邻测试覆盖两类资源的路径构建、双语搜索、稀有度与 PBE 差集。覆盖同 ID 字段变化、两类物品编号重合、传送门大小图选择。
- 验证展示方式和 PBE 新增可以同时使用。零结果时筛选仍可用。沿用棋盘目录的加载、失败和重试行为。
- 更新对应的资源指南，运行相关测试、`git diff --check` 与 `pnpm release:build`。
