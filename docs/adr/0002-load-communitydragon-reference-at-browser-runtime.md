# 将 CommunityDragon 资料移至浏览器运行时

LoL Chroma Art 将首页、臻彩详情、博客和固定说明保留为仓库数据驱动的静态图鉴内容，并把英雄、普通皮肤、皮肤系列和皮肤宇宙改为浏览器直接读取 CommunityDragon 的运行时资料。该决定让静态站能够在 CommunityDragon 不可用或断网时继续构建和发布，避免为 `pbe` 与 `latest` 生成大量实体页面，同时接受运行时资料不承担实体 SEO、源站故障会使辅助资料暂时不可用的取舍。

## 决策

- 运行时资料默认读取 `pbe`，URL 显式使用 `channel=pbe` 或 `channel=latest` 时读取对应通道；英文页面只读 `default`，中文页面只读 `zh_cn`。
- CommunityDragon 实体以数字 ID 作为跨数据通道和区域数据视图的共享身份。区域事实保持独立，缺失字段不跨区域或跨通道回退；区域记录引用的共享静态资源可以复用。
- Astro 只生成英雄、皮肤、皮肤系列和皮肤宇宙的少量列表或详情页面壳。动态详情统一 `noindex`，不进入 sitemap；旧 CommunityDragon 静态详情 URL 永久返回 404。
- 不提供全量皮肤目录，也不在系列或宇宙页面反向承诺完整皮肤集合。用户从英雄详情进入皮肤详情；系列和宇宙保留自身目录及正向关系。
- 静态臻彩页可以渐进加载少量关联资料，但加载失败不影响静态正文。英雄覆盖率文章从显式维护并提交的仓库快照生成，浏览器可以尝试刷新。
- 浏览器直接请求 `raw.communitydragon.org`，不预设本站代理、跨源或跨通道后备源，不持久化外部响应。纯领域层负责响应 Schema 与路径规范化，`src/client/communitydragon-runtime.ts` 负责请求、页面内存去重与取消；浏览器负责 HTTP 缓存与条件验证。

## 否决方案

- **`pbe` / `latest` 双静态版本树**：仍会产生大量页面，并让构建依赖外部数据。
- **一个合并的双语图谱**：容易把 `default` 的区域事实带入 `zh_cn` 页面。
- **浏览器加载完整 `skins.json`**：2026-09-20 核查时未压缩响应约为 5.9–6.2 MB，不适合作为皮肤目录或详情的默认依赖。
- **预置本站代理或持久缓存**：会增加 Cloudflare Worker、带宽、缓存失效、隐私和 Schema 迁移责任；出现真实需求时另行决策。

## 后果

CommunityDragon 资料需要 JavaScript，禁用脚本时页面壳只提供说明和导航。动态请求必须严格校验 URL 参数与必要响应契约，显示加载、空状态、失败和重试；通道切换失败时保留旧数据与旧 URL。隐私说明需披露浏览器会连接 CommunityDragon，客户端请求省略凭据和 Referer。常规测试使用固定夹具和可注入的 `fetch`，真实源站探测不进入日常测试。
