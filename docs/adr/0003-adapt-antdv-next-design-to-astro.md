# 在 Astro 中采用 Antdv Next 的设计规范

本站全站视觉统一以根目录 `DESIGN.md` 为主规范，保留 Astro 静态架构、暗色金色品牌和原画主视觉，尽量采用 Antdv Next 的控件尺寸、圆角、密度及交互状态。选择按现有 Astro 组件实现，而非迁移 Vue 与 CSS-in-JS，以保留现有数据、路由和 SEO 边界；移动端触控区域及原画展示允许有明确例外。先验收首页、图鉴、详情、博客与运行时资料的代表性基准，再推广到全站。旧视觉规范合并后删除，前端视觉任务读取 `DESIGN.md`，旧 `frontend-design` skill 移除。

夜间规范进一步采用 Antdv Next `1.6.0` 的真实暗色算法及完整官方无衬线字号体系，以黑灰表面替代旧偏蓝黑色板。最终品牌主色固定为 `#d7b56d`，保留算法生成的悬停、按下与反馈色，并为金色按钮使用深色文字。文档覆盖原始 `design.md` 的全部组件范式；页面须在代表性基准验收后对齐这些目标值。

用户后续明确授权推广到所有页面。实现集中维护主题值、通用控件和文章基础排版，局部 CSS 仅用于内容或功能确需的差异，并通过中英文、窄屏及代表页面验证共享规则。
