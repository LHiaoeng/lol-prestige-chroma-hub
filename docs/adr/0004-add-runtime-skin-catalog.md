# 增加运行时皮肤目录

LoL Chroma Art 增加可索引的双语皮肤目录页面壳，浏览器按当前数据通道和本地化视图按需读取 CommunityDragon 完整皮肤集合、皮肤系列目录与宇宙目录，并为非默认皮肤和有效皮肤阶段提供卡片、发布时间时间轴、英雄、皮肤系列和宇宙五种浏览模式；英雄按英雄分组，系列与宇宙模式按实体关系分组，并复用时间轴节点和皮肤卡片。访客需要跨英雄浏览、按稀有度筛选和搜索皮肤；沿用现有运行时资料与静态部署边界，比在构建时保存和发布完整皮肤快照更符合本站架构。目录首批显示 50 项，使用“加载更多”追加后续结果；完整集合仍按需加载一次，不使用虚拟化。

本决定修订 ADR 0002 中“不生成皮肤目录”“不提供全量皮肤目录”及完整皮肤集合仅允许三个指定入口的限制：皮肤目录是新增的第四个按需入口。其他页面仍不得默认加载完整集合；皮肤详情继续只读取所属英雄资料。目录页面壳可以进入 sitemap 并允许索引，但皮肤卡片由浏览器加载，搜索引擎未执行脚本或 CommunityDragon 不可用时只能看到页面壳。页面提供加载、空结果、失败和重试状态，不把运行时资料混入静态臻彩图鉴数据。
