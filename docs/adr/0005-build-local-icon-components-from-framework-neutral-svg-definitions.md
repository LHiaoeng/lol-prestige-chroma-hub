# 使用框架无关的图形定义建设本站图标组件

本站使用 Astro 静态页面和原生 DOM 交互，同时需要像 Antdv Next 一样按 `SearchOutlined` 等名称使用图标。采用官方 `@ant-design/icons-svg` 图形定义，建立本站命名 Astro 组件和客户端 DOM 创建入口，不引入 Vue；只公开实际使用的图标，并迁移现有通用控件中的内联 SVG。这样既复用上游图形，也避免手工维护其路径。

现有领域图标继续承载固定的资料类别语义和双语提示，图形通过统一入口渲染；上游没有语义准确的图形时保留项目 SVG。首版只支持实际调用所需的属性，后续按需加入旋转、动画和双色功能；不加载远程 iconfont 脚本，图标保持离线可用。
