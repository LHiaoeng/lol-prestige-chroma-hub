# 领域文档

工程 skill 在探索代码库时，应按以下规则使用本仓库的领域文档。

## 探索前阅读

- 仓库根目录下的 **`CONTEXT.md`**。
- **`docs/adr/`**：阅读与即将处理区域有关的 ADR。

如果这些文件不存在，**静默继续**。`/domain-modeling` skill 会在术语或决策得到明确结论时按需创建它们。

## 文件结构

本仓库采用单上下文布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 使用术语表中的词汇

输出中提到领域概念时，使用 `CONTEXT.md` 定义的术语，不要改用术语表明确排除的同义词。

如果术语表中没有所需概念，应重新考虑它是否属于本项目；如果确属缺漏，则记录下来交由 `/domain-modeling` 处理。

## 标明与 ADR 的冲突

如果输出与现有 ADR 冲突，应明确指出冲突，而不是静默覆盖既有决策。
