# LoL Chroma Art 视觉规范

## 主题色

- 名称：Chroma Gold
- CSS 变量：`--gold`
- 色值：`#d7b56d`
- 深色文字：`#121019`

Chroma Gold 是项目唯一的主题强调色。按钮、选中状态、重要标签、链接焦点和其他强调元素应优先使用 `var(--gold)`，不要在组件中重复写入十六进制色值。

## 品牌字标

品牌正式拼写为 `LoL Chroma Art`。在 Header、占位图和其他深色背景上的品牌锁定组合中，`LoL CHROMA` 使用 Chroma Gold，`ART` 使用主文字白 `#f4f0e6`。图标与字标应保持紧凑的视觉间距，作为一个整体出现，避免分散成两个独立元素。

小尺寸图标可以只显示徽标，但必须保留 `LoL Chroma Art` 的可访问名称。SEO、正文和结构化数据使用正式大小写，不沿用视觉字标的全大写形式。

占位图中的品牌组合是低对比水印，不是正式 Logo 展示位。它保留标准双色关系，但徽标使用约 `20%` 不透明度、字标使用约 `32%` 不透明度，与深色径向背景融合；不得使用 Header 的完整亮度，以免图片加载失败时抢夺页面内容层级。

`public/adsense-logo.png` 使用完整亮度的横向品牌锁定组合，导出为 PNG 或 JPG，宽高比保持 `5:1`，文件不得超过 `150 KB`。当前标准输出为 `600×120` PNG；`LoL CHROMA` 使用金色，`ART` 使用主文字白。

### 已确定用途

- 筛选区 Apply 按钮背景
- 卡片 NEW 标签背景
- 主要按钮和当前选中状态
- 重要标题、图标及交互焦点

### 使用规则

- 金色实心背景上使用 `#121019` 深色文字。
- 深色背景上可使用 `var(--gold)` 作为文字、边框或图标色。
- 大面积背景不使用主题色，避免降低原画的视觉层级。
- 发光、渐变和动画只作轻量点缀，保持简约的暗色画廊风格。
