# LoL Chroma Art 视觉规范

## 主题色

- 名称：Chroma Gold
- CSS 变量：`--gold`
- 色值：`#d7b56d`
- 深色文字：`#121019`

Chroma Gold 是项目唯一的主题强调色。按钮、选中状态、重要标签、链接焦点和其他强调元素应优先使用 `var(--gold)`，不要在组件中重复写入十六进制色值。

## 品牌字标

品牌正式拼写为 `LoL Chroma Art`。在 Header、占位图和其他深色背景上的品牌锁定组合中，`LoL CHROMA` 使用 Chroma Gold，`ART` 使用主文字白 `#f4f0e6`。图标与字标应保持紧凑的视觉间距，作为一个整体出现，避免分散成两个独立元素。

小尺寸图标可以只显示徽标，但必须保留 `LoL Chroma Art` 的可访问名称。SEO、正文和结构化数据使用正式大小写，不沿用视觉字标的全大写形式。

占位图中的品牌组合是低对比水印，不是正式 Logo 展示位。它保留标准双色关系，但徽标使用约 `20%` 不透明度、字标使用约 `32%` 不透明度，与深色径向背景融合；不得使用 Header 的完整亮度，以免图片加载失败时抢夺页面内容层级。

`public/adsense-logo.png` 使用完整亮度的横向品牌锁定组合，导出为 PNG 或 JPG，宽高比保持 `5:1`，文件不得超过 `150 KB`。当前标准输出为 `600×120` PNG；`LoL CHROMA` 使用金色，`ART` 使用主文字白。

### 已确定用途

- 筛选区 Apply 按钮背景
- 卡片 NEW 标签背景
- 主要按钮和当前选中状态
- 重要标题、图标及交互焦点

### 使用规则

- 金色实心背景上使用 `#121019` 深色文字。
- 深色背景上可使用 `var(--gold)` 作为文字、边框或图标色。
- 大面积背景不使用主题色，避免降低原画的视觉层级。
- 发光、渐变和动画只作轻量点缀，保持简约的暗色画廊风格。

## 返回顶部

全站使用右下角悬浮的圆形返回顶部按钮。页面滚动超过 `480px` 后显示，主体使用 `var(--gold)`，图标使用 `#121019`。移动端必须适配安全区；用户启用“减少动态效果”时，禁用淡入与平滑滚动。

## Header 控件

语言切换器使用紧凑的金色描边胶囊，视觉高度约为 `32px`。组件外围保留约 `44px` 的透明点击区域，避免为追求紧凑而牺牲移动端可用性。

Header 全站共用一层玻璃：底色固定为 `color-mix(in srgb, var(--bg) 48%, transparent)`，`backdrop-filter` 为 `blur(4px) saturate(165%) brightness(.96)`。底色不随滚动变化，页面一打开就能透过 Header 看到底层图像；滚动收窄状态只额外增加外阴影与底部分隔线，不改透明度。参数要求透出底层图像的清晰轮廓而不是只剩色块，所以模糊半径保持在 5px 以内、亮度不低于 `.95`。Header 内文字统一使用 `0 1px 7px #000000d9` 阴影，保证压在浅色图上时仍可读。不支持 `backdrop-filter` 时回退到 97% 不透明的深色 Header。

## 全端首屏背景

首页和博客列表页共用 `ResponsiveHeroBackdrop` 组件。组件在桌面端加载大图、在 `767px` 及以下加载中图，并统一处理渐变遮罩、轻微漂移、鼠标视差和减少动态效果。

首屏背景从视口顶部开始：背景容器向上延伸 `var(--site-header-height)` 覆盖 Header 之后，高度取 `100svh`，内容再用等量 `padding-top` 补偿，保证正文位置不变。这样 Header 玻璃在页面初始状态就能采样到背景，观感与皮肤详情页的固定背景一致；首页 `.hero-section`、博客列表页 `.blog-hero` 用负 `margin-top` 整体上移，臻彩详情页 `.detail-background` 直接改 `inset` 与高度。改用 `100svh` 而不是 `calc(100svh - var(--site-header-height))`，仍可避免移动端浏览器栏导致的溢出。遮罩渐变使用百分比停靠点，不使用固定 `vh` 位置。博客背景仅覆盖首屏，但标题与文章列表共用内容容器，让首篇文章在首屏内开始展示并自然延续到下方深色内容区；视差交互也只在首屏内响应。

## 皮肤详情展签

`/skins/{slug}/` 及中文页面使用“单幅主展墙 + 下置展签”布局：桌面原画占据最大 `1440px` 宽的首要位置，保持自身比例完整展示；作品名称、英雄链接和三列档案数据编排在原画下方，不与作品抢夺水平空间。主展墙是唯一的原画媒体入口，只使用“静态原画”和“动态原画”两枚图标按钮：点击切换媒体类型，连续点击当前类型时在实际存在的聚焦/非聚焦版本间循环。当前按钮以金色选中态和右上状态标记表达媒体与聚焦状态，标题、提示和可访问名称同步告知下一次点击结果。缺失某类资源时不渲染其按钮或占位面板；运行时加载失败的媒体从可用集合移除并自动回退到剩余优先资源。有动态资源时默认显示动态，优先聚焦版，静态原画继续复用全屏图片查看器。细金色角标、低饱和背景与金色提示建立层级，不在作品上叠放正文。页面底层优先使用聚焦动态原画（静音自动循环播放），背景降低饱和度和透明度，滚动时保持不动，只提供作品氛围。1023px 及以下展签改为单列；手机主展墙保留 `--page-gutter` 安全边距，炫彩固定两列。作品简介采用侧标与正文的编辑式排版，后续区块保持与内容网格对齐。样式限定在皮肤详情内。


背景覆盖整个视口并延伸到 Header 之后，Header 沿用全站玻璃参数，让原画轮廓透过 Header 可见；不做页面级覆盖。
