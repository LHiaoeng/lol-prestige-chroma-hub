# Chroma Art 视觉规范

## 主题色

- 名称：Chroma Gold
- CSS 变量：`--gold`
- 色值：`#d7b56d`
- 深色文字：`#121019`

Chroma Gold 是项目唯一的主题强调色。按钮、选中状态、重要标签、链接焦点和其他强调元素应优先使用 `var(--gold)`，不要在组件中重复写入十六进制色值。

### 已确定用途

- 筛选区 Apply 按钮背景
- 卡片 NEW 标签背景
- 主要按钮和当前选中状态
- 重要标题、图标及交互焦点

### 使用规则

- 金色实心背景上使用 `#121019` 深色文字。
- 深色背景上可使用 `var(--gold)` 作为文字、边框或图标色。
- 大面积背景不使用主题色，避免降低原画的视觉层级。
- 发光、渐变和动画只作轻量点缀，保持简约的暗色画廊风格。
