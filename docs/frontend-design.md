# 前端规范

视觉规则见 [DESIGN.md](../DESIGN.md)，浏览器主题变量见 [tokens.css](../src/styles/tokens.css)。组件实现与测试在 [src/components](../src/components/)。组件变更执行 [上游对照与验收](antdv-next-component-replication.md)，页面结构与响应式见 [页面模板](page-templates.md)。

## 共用规则

- 使用语义 Token 表达主题色、字号、间距、圆角和动效。布局和媒体比例由调用方决定。只有浏览器状态或事件需要客户端脚本。
- 通用图标使用 [命名 Astro 组件](../src/components/icons/) 或客户端 [createIcon](../src/components/icons/create-icon.ts)。颜色继承 `currentColor`。装饰图标对辅助技术隐藏，纯图标控件由调用方提供双语名称。领域图标的名称和 Tooltip 统一在 [domain-icons.ts](../src/components/domain-icons.ts) 维护。
- 召唤师图标、表情和守卫皮肤的 SVG 轮廓取自 Riot 客户端战利品分类 PNG。使用正方形画布、`1em` 外框和 `currentColor`，目录标题、导航与 PBE 新增分类共用同一套图形。 [Riot 客户端分类资源](https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-loot/global/default/assets/category_icons/) · [上游 IconBase](https://github.com/antdv-next/icons/blob/main/src/components/IconBase.tsx)
- 英雄和皮肤分别取自 [本站标志](../public/logo.svg) 的底层头盔和上层面具。两条原始路径分别等比映射到共享的 24 单位画布，均使用 `currentColor` 填色。
- 皮肤宇宙使用基于 Riot 三面具的本站小尺寸变体，保留中央面具，收窄两侧面具，使可见高度接近皮肤系列双面具。路径直接使用调整后的坐标，沿用共享的 1em × 1em 外框。 [客户端 SVG](https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-static-assets/global/default/images/skin-viewer/icon-three-masks-default.svg)
- 皮肤系列复用 Riot 客户端皮肤预览栏的双面具路径。放大和居中直接写入路径坐标，保留原始长宽比。图标使用按可见轮廓宽度裁切的正方形画布，在共享的 1em × 1em 外框内等比显示，填色继承 `currentColor`。 [客户端 SVG](https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-static-assets/global/default/images/skin-viewer/icon-themes-default.svg)
- 英雄职业筛选使用 Riot 客户端收藏模块的两张职业图集。按客户端样式的坐标呈现六个职业，选中时显示高亮版。共享 Select 允许选项和选中值在文字前显示装饰图标，中文和英文职业名称仍作为可访问标签。[客户端职业图集样式](https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-collections/global/default/rcp-fe-lol-collections.css) · [Antdv Next Select](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/select/index.tsx)
- 回归检查以 [AGENTS.md](../AGENTS.md) 为准。当前项目使用相关测试和真实页面检查验证视觉改动。

## 组件用法

- **FloatButton.BackTop**。[BaseLayout](../src/layouts/BaseLayout.astro) 统一挂载中英文返回顶部按钮。默认圆形按钮达到 400px 时显示，距右 24px、距底 48px，计入安全区。皮肤详情的底部切换栏避开按钮。[上游对照与验收](../src/components/back-to-top.md)

- **Header**。英雄联盟和云顶之弈使用 [Dropdown](../src/components/dropdown.md)。当前路由在菜单项上用 `aria-current`。右侧入口使用 [上游文字按钮](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/button/style/variant.ts) 横向紧邻排列，桌面采用默认尺寸，窄屏采用小号。语言切换和博客保留链接语义。Header 博客入口与首页博客标题复用 Ant Design 的 FileTextOutlined，图标隐藏于辅助技术，入口保留文字标签。语言字牌参照 [官网 SwitchBtn](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/docs/src/layouts/base/components/switch-btn.vue)。游戏图标使用同一 `1em` 外框，LOL 图形按可见轮廓映射到 24 单位画布。窄屏隐藏标签时保留可访问名称。
- **Radio.Button**。[RadioButtonGroup](../src/components/RadioButtonGroup.ts) 默认描边，选中项使用主色文字和边框。皮肤目录加载时同步禁用，窄屏横向滚动。Tooltip 包装后仍只让首尾项保留外侧圆角，相邻边框重叠 1px。皮肤媒体和小小英雄视图显式使用实色。 [上游 Radio 样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/radio/style/index.ts)
- **Select**。[Select.astro](../src/components/Select.astro) 默认不显示清除按钮，使用 `allowClear` 显式开启。清空在原生 `<select>` 上派发冒泡 `change`。`showSearch` 默认关闭，开启后按标签做不区分大小写的包含匹配，支持 `optionFilterProp="value"` 和 `filterOption={false}`。输入通过可冒泡的 `search` 事件传出查询字符串。下拉选项使用单行显示。外观目录通过 `popupMatchSelectWidth={false}` 让弹层按内容扩宽，超出可用宽度时可横向滚动。上游默认对过长选项使用省略号。 [上游下拉选项样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/select/style/dropdown.ts#L108-L114) 下拉滚动条保持可见，边框菜单使用独立 SVG 箭头并垂直居中。无脚本时保留原生选择框。 [上游 Select 样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/select/style/index.ts)
- **Card Tabs**。[Card.astro](../src/components/Card.astro) 支持 `small` 和 `medium`。页面链接保留原生导航语义。本地页签通过 `activeTabKey` 或 `defaultActiveTabKey` 选定面板，支持方向键、Home/End 和 `card-tab-change`。选中指示线对齐页签行的底部内侧。本站的页签容器仅在宽度不足时原生横向滚动，上游容器裁切溢出并提供更多操作。 [上游 Tabs 样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/tabs/style/index.ts#L450)
- **首页新增臻彩 Collapse**。窄版心采用上游默认描边的单面板，使用 12×16px 标题内边距、8px 圆角、左侧箭头和展开旋转，背景按主题映射到填充色与卡片色。本站用原生按钮和 `aria-expanded` 管理状态，用 CSS 驱动高度与透明度动画并响应减少动态效果。宽版心直接显示同一组内容，无脚本时展开内容。此处仅接入单面板，无分组和手风琴配置。 [上游 Collapse 样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/collapse/style/index.ts) · [上游箭头和默认状态](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/collapse/Collapse.tsx)
- **Card 悬停与焦点**。通用 Card 默认 `hoverable`；全站卡片默认使用 `--line` 和 `--shadow-card`。鼠标悬停或卡内出现 `:focus-visible` 时，整卡同步使用 `--gold` 边框和 `--shadow-card-highlight`，两种状态同时存在时任一状态结束都不会提前复位。嵌套卡片只强调最内层；整卡链接使用卡片边框表达焦点，卡内按钮仍保留自己的焦点环。状态过渡使用 `--motion-mid`；卡片位置、背景和封面尺寸保持稳定。预览和卡片操作入口仍由各自规则显隐。实现依据为固定版本 [Antdv Next Card style-class 示例](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/docs/src/pages/components/card/demo/style-class.vue#L21)。
- **Card 标题**。固定上游 [Card 头部样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/card/style/index.ts#L98) 默认采用 16px 强字重，小号卡头使用 14px；[Card.Meta 标题样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/card/style/index.ts#L230) 使用 16px、`colorTextHeading`、强字重和文本省略。本站有意将这些卡头与正文标题合并为 14/22px、600 字重和主文本色，以增加窄卡名称与资料空间。卡头、正文、封面叠字、文章卡和资料树顶层名称均单行省略；仅溢出标题显示全名。样式集中于 [global.css](../src/styles/global.css)，溢出状态由 [card-title.ts](../src/components/card-title.ts) 按实际布局同步，动态列表、视图切换和视口变化也会重新检查。读屏仍读取完整文本，已有详情或资料入口保留原语义；博文占位卡用原生 `details/summary` 提供触屏和键盘的全名展开。
- **Tooltip**。上游 [Tooltip 文档](https://www.antdv-next.com/components/tooltip-cn.md) 将其用于鼠标移入显示、移出隐藏的简短提示，并可代替系统 `title`。本站在 Astro 中用 [tooltip.ts](../src/components/tooltip.ts) 复刻浮层：`createTooltip` 包装已有触发器，`bindTooltip` 原位绑定卡片标题以避免改变卡片布局。卡片标题只有实际溢出时才绑定 Tooltip；悬停和键盘聚焦显示全名，尺寸或内容变化后移除／更新提示。本站保留顶部／底部自动定位；上游其他方向、自定义对齐、箭头开关和受控显隐不属于本次标题使用范围。
- **媒体预览与下载**。[页面模板](page-templates.md#详情页媒体相册) 规定预览交互。[ImageViewer](../src/components/ImageViewer.astro) 的 `downloadFilename` 和动态触发器的 `data-preview-filename` 均使用共享下载方法。文件名优先取指定名，其次取当前媒体名和资源文件名，优先保留源扩展名。按 Windows 命名规则清理并进行 Unicode 规范化，文件名最多 240 个 UTF-8 字节。
- **BorderBeam**。[共享实现](../src/components/border-beam/) 按 [上游样式](https://github.com/antdv-next/antdv-next/blob/839bec66f18a78eeef5c6843b78ea4a54d73b248/packages/antdv-next/src/border-beam/style/index.ts) 绘制遮罩与圆角路径。皮肤详情只为目录匹配的臻彩启用流光，颜色来自主题金和该记录的全部 `colors`。每种颜色独立渲染并均匀错开相位。首页 Card Tabs 通过 `tabBorderBeam` 提供三条渐变。动画层贴合外边框，卡片根保持 `overflow: visible`，装饰层不捕获指针。减少动态效果或能力不支持时保留静态边框。
