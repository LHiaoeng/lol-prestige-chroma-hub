# 页面模板契约

新增或重做页面时，先选页面类型，再按通用骨架组装；修改现有页面布局或响应式时核对对应契约。复用现有 [BaseLayout](../src/layouts/BaseLayout.astro)、[Breadcrumb](../src/components/Breadcrumb.astro) 和组件。视觉值以 [DESIGN.md](../DESIGN.md) 与 [tokens.css](../src/styles/tokens.css) 为准。

## 通用骨架

1. `BaseLayout` 接收本语言的标题、描述、canonical、locale，以及适用的结构化数据；它负责站点 Header、`<main>`、Footer、语言切换和 [返回顶部](../src/components/BackToTop.astro)。Header 将英雄、系列、宇宙和 PBE 新增入口收在“英雄联盟”下拉中，桌面与窄屏共用同一交互。页面不重复放置返回顶部按钮。
2. 有上级的页面在 Header 下、标题前放 `Breadcrumb`。它与页面版心容器作为 `<main>` 的同级内容排列，不放进 `.runtime-page` 等已设版心或横向留白的容器，避免二次缩进；面包屑与后续第一个内容块统一间隔 `--space-3`，内容容器不再增加顶部间距。首项链接到本语言首页，中间项链接到上级，末项是当前页纯文本；文章使用 `article` 变体。首页与无确定上级的 404 页省略面包屑。
3. 页面内容使用唯一的 `h1`，下面依次放简短说明、适用的操作和主体内容；主体内容按 `h2` 分节。动态区域只负责动态结果，加载、空、错误和重试状态在此就地呈现并提供文字反馈，不改变面包屑、标题和页面版心容器的层级；CD 详情页的实体标题及面包屑末项由成功加载的实体名称填充。

## 动态资料展示结构

- **列表页共用排版**：面包屑 → 主题色领域图标与目录名称 `h1` → 共享版本切换、垂直 Divider 和结果数量 → 水平 Divider → 筛选、排序与结果卡片。列表页不显示说明文案；英雄、系列和宇宙目录使用响应式 Masonry，不分页。宇宙卡片用不可展开的 Tree 常显宇宙与所属系列关系。
- **详情页共用排版**：英雄、皮肤、皮肤系列与宇宙详情依次显示面包屑 → 主题色领域图标与实体名称 `h1` → 有内容时用 Typography.Paragraph 显示简介，沿用默认字号、文字色、行高和行内展开操作；桌面完整显示、手机最多两行并可展开/收起 → 共享版本切换行（有信息时用垂直 Divider 分隔）→ 水平 Divider → 主体内容。英雄 `h1` 显示称号与名称；英雄在版本后显示皮肤总数；皮肤系列在版本后显示所属宇宙与皮肤总数；皮肤在版本后显示所属英雄（有称号时同时显示称号）、系列与宇宙；摘要行和炫彩分节标题都显示炫彩数量（不含基础皮肤），摘要中的炫彩数量链接到炫彩分节。关联名称按数据就绪分别填充，头部已有的所属关系不在正文重复。主体按资料类型组织：英雄直接展示包含默认皮肤的皮肤列表，皮肤详情的 h1 有稀有度图标时显示该图标；悬停时先预览皮肤徽章（有徽章时），再显示稀有度名称；没有稀有度图标时显示皮肤领域图标，有徽章时悬停同样先预览徽章；媒体与边框预览使用版心宽度的手动轮播，媒体画面不重复显示标题，底部互斥按钮分别对应可用媒体与边框。静态和动态原画各占一个轮播控制项，控制项再次点击切换聚焦/非聚焦版本；皮肤缩略图及载入图各占一个控制项，默认优先显示聚焦动态原画，其次聚焦原画。点击媒体打开统一全屏相册预览，同组包含全部可用媒体，按媒体项目顺序以两侧切换按钮、底部计数和方向键浏览；关闭相册时，轮播选中项及聚焦/非聚焦状态同步到最后查看的媒体。图片与视频均按视口等比最大完整展示，复用 Antdv Next Image 的缩放、拖动、旋转、双轴翻转与双击复位交互，并提供重置与下载当前媒体原文件的按钮；下载默认使用当前媒体名称，允许调用方传入文件名，并由共享下载方法统一处理系统命名限制。两者共用固定位置的主工具栏；视频播放、进度与音量控件位于主工具栏上方，独立于画面的变换。预览衔接页面视频的进度、音量与播放状态，切换时暂停离开的媒体，关闭时同步进度并按进入前的状态恢复页面视频；进度与音量控件上的方向键不切换媒体。统一提供加载、失败与重试状态，窄屏工具栏不溢出且避开安全区。预览图像的遮罩、居中媒体、关闭/切换按钮和底部工具栏布局按上游 Image 源码实现。动态原画在当前显示时静音循环播放，切换离开后暂停；手机端将媒体选项排成两列，并将下载按钮设为 Block 满宽。其余主体展示炫彩；皮肤详情炫彩区仅在存在基础皮肤炫彩原画时显示基础皮肤卡片；缺少原画时显示 Empty 状态，不回退使用基础皮肤缩略图；实际炫彩卡片仍按两列显示。默认皮肤没有自身描述时显示英雄简介；系列展示皮肤，宇宙展示筛选与系列皮肤。适用的内容分节使用 `h2`；缺失的简介和摘要字段不留空占位。
- **头部信息与关联入口**：详情页由 [RuntimeDetailSummary](../src/components/RuntimeDetailSummary.astro) 统一组装摘要行并管理其专属样式，版本下拉复用 [RuntimeChannelSwitcher](../src/components/RuntimeChannelSwitcher.astro)。版本切换是操作控件；其后的所属关系与总数是当前实体的摘要信息，按“领域图标＋名称或数量”排列，并用垂直 Divider 分隔。运行时资料详情与臻彩详情的摘要行中，每个图标都使用站内 Tooltip，悬停或键盘聚焦时显示它代表的具体项名称：Tooltip 交互由共享 [tooltip.ts](../src/components/tooltip.ts) 实现，领域名称和中英文标签统一维护在 [domain-icons.ts](../src/components/domain-icons.ts)；关系项在类别名称后显示当前关联实体，数量项显示类别与实际数量，版本图标显示当前资料版本，“更多”图标显示摘要扩展内容。各页面只提供实体名称、数量或版本等动态值，不自行实现 Tooltip 样式或重复定义领域名称。皮肤详情摘要行显示当前皮肤的炫彩数量（不含基础皮肤）。有摘要扩展内容时，在摘要行末尾显示工具箱图标标识的“更多”Dropdown，统一收纳当前实体的摘要扩展内容，例如第三方入口和其他补充工具；无扩展内容时不显示该项。整行使用比默认正文大一档的 16/24px 字体规格，版本控件与分隔线继承该规格；各信息项之间以及图标与文字之间共用同一横向间距 Token，分隔线自身不叠加边距。加载时只显示一条与摘要行对齐的短骨架；数据就绪后整行替换。可跳转的所属关系使用普通行内文字链接，保留悬停与键盘焦点反馈，不套用按钮或芯片外观；无目标的数量使用纯文本。头部已有的关系不在正文重复成节，确需展开说明或展示集合时再设独立章节。
- **共用加载与显示规则**：列表与详情使用同一动态状态流程和共享版本切换组件，骨架按各自真实排版占住标题、操作与主体位置：列表卡片沿用对应目录的列宽与卡片高度，系列卡片包含标题与所属宇宙标签占位；皮肤详情媒体按轮播区域和媒体比例占位，PBE 对比页先占住版本、摘要与分类区域。加载完成后由真实内容替换，并以短暂淡入呈现；减少动态效果时取消淡入和骨架流光。失败或无效资料时移除对应占位；不让骨架与真实内容同时显示。详情页摘要行在版本、所属关系和数量所需数据仍在加载时只显示单条骨架，待这些字段全部就绪后一次性展示，不逐项露出真实内容；空结果或失败也应结束骨架，并在对应位置隐藏无数据字段或提供重试。加载状态提供文字反馈，主数据的错误显示 Alert 与重试；列表无结果显示 Empty。正文关联资料仍独立加载，只在所属区域显示占位、结果或失败重试，不重置已加载的主数据。首次加载使用骨架；切换资料版本时保留已加载的标题、摘要、正文和背景，确认目标资料后再更新。目标实体明确缺失时先确认回退目标可用，再以普通导航进入该目标通道并显示可刷新的双语说明；请求失败时保留原内容与地址并提供重试。标题图标、字号、间距和 Divider 均复用共享组件与设计 Token，保持版心和内容顺序一致。
- **特有展示**：宇宙详情在简介后显示版本与领域图标数量，系列标题使用可跳转的主题色图标 `h2`，系列筛选与英雄/稀有度排序位于同级工具栏；皮肤系列详情的皮肤列表使用英雄/稀有度排序，英雄详情只提供发布顺序/稀有度排序。筛选控件在列表上方同级排列，头部数量表示当前版本的总量，不随排序改变；缺少匹配结果时显示空状态。详情页皮肤卡片标题使用稀有度图标与名称，名称单行省略，悬停或键盘聚焦时用 Tooltip 显示完整名称与稀有度；目录页皮肤卡片沿用来源载入图的 11:20 纵横比，缺图时保留比例并居中显示占位，按版心使用 6/4/3/2 列，名称完整显示并允许自然换行，列间距为 16px、行间距为 24px；中文目录卡片在名称上方显示来源 `emblems[].emblemPath` 指向的皮肤徽章，悬停或键盘聚焦时通过共享 Tooltip 显示原图，并由与批量边框切换并排的工具栏默认开启复选框统一控制显隐，无徽章时不显示占位；目录不提供按英雄/按系列浏览切换；边框、皮肤徽章、经典皮肤与 PBE 显示选项在工具栏左侧成组排列，排序选择器靠右且不显示标题；PBE 新增皮肤卡片左上角显示文字角标“PBE”，桌面端在卡片悬停或键盘聚焦时显示 PBE 角标和单卡边框切换，触屏设备保持可见；默认未勾选的“PBE新增”复选框筛选 PBE 新增皮肤，取消勾选时显示全部皮肤；稀有度选项按稀有度从高到低排列，缺少稀有度的选项显示“其他”；工具栏提供默认勾选的“经典皮肤”选项，按皮肤名称前缀匹配“经典”或 `Classic`，取消勾选时排除匹配项。稀有度提示使用共享 Tooltip，仅绑定原有稀有度图标。目录结果按普通页面滚动，首批显示 50 张；底部使用 Antdv Next 默认 Button 样式居中，顶部间距 12px，每次点击追加最多 50 张，加载完毕后隐藏按钮，不使用虚拟化。可用载入边框的皮肤提供单卡切换，工具栏“边框”复选框批量切换全部可用皮肤的带框/原始载入图；统计通过共享 Tooltip 在悬停或聚焦控件时显示，默认显示带框模式；单卡设置后全局复选框显示半选状态。
- **皮肤目录发布时间排序**：默认按发布时间最新优先，并保留英雄名称排序与发布时间最早优先；中文页优先国服日期，空值回退直营服日期，英文页采用直营服日期。PBE 新增皮肤在两种方向下均排在有日期的皮肤之前，其余无日期皮肤排末尾；同一天、未知日期和 PBE 新增组内均按英雄 ID 升序，同一英雄再按皮肤与阶段顺序稳定排列。排序保留在 URL 中。
- **皮肤目录卡片操作**：边框切换与详情操作使用 Antdv Next Button 的 `small` 图标按钮（24px）。桌面端在卡片悬停或键盘聚焦时显示，触屏设备保持可见；边框按钮在上，信息按钮在下。信息按钮悬停或键盘聚焦时打开 Popover，点击可固定开合；点击外部或按 `Esc` 关闭，浮层在视口边缘自动调整位置。Popover 展示英雄、皮肤、稀有度、发布时间与炫彩数量摘要，缺失字段不显示。Popover 的触发与标题/内容结构、箭头和视觉样式按 [Antdv Next Popover 组件源码](https://github.com/antdv-next/antdv-next/blob/fa18c3e46dea32449fa5cb1eda175e3f10a3bb74/packages/antdv-next/src/popover/index.tsx)、[样式源码](https://github.com/antdv-next/antdv-next/blob/fa18c3e46dea32449fa5cb1eda175e3f10a3bb74/packages/antdv-next/src/popover/style/index.ts)、[圆角箭头源码](https://github.com/antdv-next/antdv-next/blob/fa18c3e46dea32449fa5cb1eda175e3f10a3bb74/packages/antdv-next/src/style/roundedArrow.ts) 与 [Popover 标题和内容结构源码](https://github.com/antdv-next/antdv-next/blob/fa18c3e46dea32449fa5cb1eda175e3f10a3bb74/packages/antdv-next/src/popover/PurePanel.tsx) 复刻，MIT 许可见 [popover/LICENSE](../src/components/popover/LICENSE)。
- **状态决定控件**：加载中以同尺寸骨架占住可用的筛选和排序位置；成功且有可操作的结果时才显示真实控件。主数据为空或失败时移除筛选与排序，直接展示 Empty 或 Alert 与重试；局部关联资料失败时只替换该区域。版本切换、重试和筛选后的空结果分别验收，不能留下已结束的骨架、旧版本数量或与当前结果无关的控件。
- **骨架与结果逐项对齐**：首次加载使用与结果逐项对齐的骨架；切换版本时保留已有结果直至目标确认可用，不重复显示骨架；按真实页面核对标题图标、标题与简介行高、摘要首行、Divider 宽度、筛选栏高度、卡片列宽与内容高度、媒体比例及区块间距。皮肤详情摘要与媒体标题之间只保留一条水平分割线，媒体标题含领域图标占位，媒体骨架沿用实际 16:9 区域与控制行；皮肤详情同时显示方形炫彩卡片骨架，并跟随手机端两列布局。卡片高度由内容决定时，骨架跟随该类型的实际卡片，不用统一的大块占位；缺失字段和空结果不保留无意义高度。检查从骨架到结果的前后画面，而非只检查其中一个状态。
- **领域标识统一**：目录和详情的 `h1`、分组 `h2`、摘要及关联入口复用 [领域图标映射](../src/components/domain-icons.ts) 中相同语义的图标；图标以 `1em` 跟随文字大小并继承主题色，和文字垂直居中。名称、数量与操作各有固定语义位置，不因页面或资料版本重新定义图标、字号或间距。
- **CD 二级标题**：运行时资料详情与 PBE 分类的每个 `h2` 前都显示适合该标题语义的领域图标，通过共享 `createDomainHeading` 和 `runtime-section-heading` 样式实现，不在各页面分别设图标或排版。皮肤的“媒体”使用多媒体图标，“历史版本原画”使用皮肤图标，“炫彩”使用臻彩图标；皮肤系列详情中的皮肤分组使用皮肤图标；宇宙详情中的系列分组使用皮肤系列图标。PBE 已映射到领域的分类使用对应图标，图标、表情、边框、守卫皮肤和终结特效等没有专属映射的分类使用 PBE 新增图标。标题统一使用主题色、600 字重和 `--font-size-headline-sm` / `--line-height-headline-sm`；图标为 `1em`，与文字间隔 `--space-2`。标题自身不加外边距，区块容器用 `--space-*` 控制间距。图标按装饰内容隐藏于辅助技术，标题文字保留完整语义。
- **详情页模块分隔**：主体中的原画、资料和关联分组等模块之间使用共享水平 `Divider`；线前后间距使用 `--space-4`，不以模块边框重复绘制分隔线。
- **臻彩原画**：使用版心全宽的 16:9 画板，图片以 `cover` 铺满画板；桌面与手机保持相同媒体比例。

### 详情页媒体相册

皮肤媒体与炫彩卡片使用同一全屏相册预览。炫彩原图和臻彩原图分别组成独立相册；匹配到臻彩目录的卡片通过图片切换选择对应相册，关闭相册时卡片显示状态跟随最后查看的版本。未匹配臻彩目录的炫彩和原始皮肤图只进入炫彩原图相册。炫彩标题按实际炫彩数显示为“炫彩（N）”或“Chromas (N)”，数量与标题同样式，不计原始皮肤图。
炫彩卡片右上角的图片切换和信息操作沿用皮肤目录卡片的 small 图标按钮与显隐方式，图片切换使用双向箭头图标并置于上方，圆圈 i 信息按钮置于下方。信息按钮悬停或点击打开 Popover；中文标题按普通炫彩或臻彩显示“炫彩详情”或“臻彩详情”，英文统一显示“Chroma Details”。3D 模型入口使用左侧模型图标、简洁文案和右侧外链图标；中文文案为“去卡达查看3D模型”，链接至布锅锅并传入皮肤 ID 与炫彩 ID；英文链接至 KHADA。
详情页摘要行的“更多”菜单每项按目标用途显示左侧图标、简洁文案和右侧外链图标；文案不包含具体英雄或皮肤名称。英雄与皮肤详情的菜单包含中英文“维基百科”/“Wiki”入口，指向对应英雄的 League of Legends Wiki 页面；中文英雄与皮肤详情另含“对战数据”入口，按英雄 ID 打开腾讯英雄详情。

### 皮肤详情切换

皮肤详情页在宽屏时于版心左右两侧、视口垂直中线显示固定的上一款/下一款 Antdv Next 文本按钮，按钮内包含朝向版心排列的箭头与目标皮肤名；不足 1600px 的视口改为避开底部安全区和返回顶部按钮的双列悬浮文本按钮，皮肤名最多显示两行，避免遮挡炫彩卡片。滚动接近 Footer 时，按钮组上移并停在 Footer 上方；空间不足时隐藏，避免遮挡 Footer。点击按钮或按 ← / → 都按英雄详情页“发布顺序”切换，包含基础皮肤和阶段项，并保留页面滚动位置；首尾循环，只有一款时禁用按钮。媒体相册打开或焦点位于交互控件时，方向键保留给当前控件。

## 宽度

- 列表、详情和普通页面沿用共享版心：`width: min(var(--content-width), calc(100% - (var(--page-gutter) * 2)))`，水平居中。面包屑已有相同版心，不再叠加横向留白。
- 页面默认内容容器占满共享版心，不额外缩窄，也不超过版心宽度；仅图片、专属网格、图表和浮层等有明确功能或媒体需求的元素局部限宽。
- 长文沿用 [article.css](../src/styles/article.css) 的外层版心；正文、导语、图片和表格默认使用完整版心宽度。关于页和隐私页正文同样沿用各自版心。
- 背景与原画可铺满视口，标题、正文、导航和操作仍与版心对齐。间距用现有 `--space-*`；手机边距由共享样式覆盖。

## 固定背景媒体

- 页面级背景由 [BaseLayout](../src/layouts/BaseLayout.astro) 全局加载 [backgrounds.css](../src/styles/backgrounds.css)。页面直接使用模块类，不重复导入样式，也不自行实现 `position: fixed`、视口尺寸、媒体裁切和层级。
- Header 与 Footer 由 `BaseLayout` 保留在背景之上；页面模板只放背景和页面内容，不隐藏、替换或用全屏层覆盖 Footer。
- 按页面层级选择模块类：首页使用 `page-backdrop page-backdrop--home`，并让页面建立 `isolation: isolate` 的层叠上下文、前景内容设为 `z-index: 1`；其他页面使用 `page-backdrop page-backdrop--behind`，并确保其所在页面层叠上下文隔离。详情页可额外使用 `page-backdrop--detail` 获得详情专用遮罩。背景包裹层使用 `aria-hidden="true"`，不得承载交互或唯一信息。
- 页面结构按此模式组装，背景与正文同属页面模板，但背景固定于视口：

  ```astro
  <BaseLayout title={title} description={description}>
    <div class="page-backdrop page-backdrop--behind" aria-hidden="true">
      <!-- ResponsiveHeroBackdrop 或 picture/img -->
    </div>
    <!-- 面包屑、标题和正文 -->
  </BaseLayout>
  ```

- 需要响应式取图、叠加层和已有图片回退逻辑时，在 `.page-backdrop` 内使用 [ResponsiveHeroBackdrop](../src/components/ResponsiveHeroBackdrop.astro)；详情等静态背景使用 `<picture>` / `<img>`，并给装饰图设置 `alt=""`。背景失效或不可用时，主体内容与阅读顺序保持不变。
- 固定背景不得置于带 `transform`、`filter`、`perspective` 或裁切的祖先下，以免固定定位变成局部定位或被截断；背景层不遮挡交互，Header 和前景内容保持在背景之上。
- 背景按本站断点适配：桌面（≥1024px）使用大图与宽屏遮罩；平板（768–1023px）保留大图清晰度并调整遮罩和动效；手机（≤767px）使用中图、单独调整构图和遮罩。平板与手机均关闭漂移动画，保持正文对比度并减少小屏开销。
- 背景图片以 `object-fit: cover` 填满视口；叠加渐变或遮罩，保证前景文字对比度。图片加载失败时依次尝试已配置的备用图片和占位图；都不可用时保留 `var(--bg)` 等主题纯色底，不显示破图图标。
- CD 详情页统一在共享模板中渲染固定全屏详情背景。英雄详情从该英雄的非基础皮肤中选择稀有度最高、最新的一款；系列和宇宙详情从各自的皮肤集合中选择；皮肤详情只使用当前皮肤或当前阶段的原画，每个阶段按独立皮肤展示。首选非聚焦原画；该原画缺失时使用当前皮肤或阶段的聚焦原画，加载失败时再回退其缩略图和占位图；无可用原画或媒体均失败时保留主题纯色底。CommunityDragon 未提供皮肤发布日期，最新暂按皮肤 ID 倒序判断。背景只作装饰，不改变标题骨架、正文版心、Footer 或信息顺序。
- 背景视频同样只作装饰，静音、内联播放、循环播放并提供静态 `poster`；视频未能加载、播放或自动播放时显示 `poster`/备用图片，静态资源也失败时回退到主题纯色底。共享模块目前只提供视频的固定定位和铺满视口样式，使用视频的页面还须实现上述媒体回退；视频不承载唯一信息，不提供会抢占焦点的控件。
- 尊重 `prefers-reduced-motion`：减少动态效果时停止背景视频与视差/漂移动画，显示静态图片；自动播放受限、节省流量或媒体格式不支持时也采用静态兜底。

## 类型差异

| 类型 | 在通用骨架上补充 |
| --- | --- |
| 首页 | 可用视觉隐藏的 `h1`；主题区块用 `h2`，提供内容入口和主要目录。 |
| 列表 / 搜索 | 结果列表与空/失败状态；有筛选需求时提供筛选、排序和结果数量。内容高度不一时可使用 Masonry；数据量和任务需要分页时才提供分页。 |
| 详情 | 主媒体或关键资料、相关操作、补充资料；处理缺失字段和图片失败。以原画为视觉焦点时可隐藏 `h1`，但可见名称须清晰。 |
| 运行时资料（CD） | 列表与详情的排版、骨架及共用加载状态见上方“动态资料展示结构”；固定全屏背景和媒体回退见“固定背景媒体”。皮肤详情媒体使用 Carousel 与 Radio.Button 控制；媒体选择和图标下载按钮共用紧凑控制行，以垂直 Divider 分隔。本地 RadioButtonGroup 与 Button 均通过 `size` 属性控制 small/middle/large 尺寸，轮播使用 middle（默认 32px），手机端媒体选项为两列，下载按钮使用 Button 的 Block 属性铺满控制区；控件高度仍由组件尺寸控制。下载操作始终对应当前媒体。边框页默认显示合成载入图，并可切换为透明边框图。水平和垂直分割线使用共享 Divider。首次加载无原画时显示主题底色，切换版本期间保留当前背景，待新资料就绪后更新。PBE 对比页在版心内依次显示领域图标与独立 `h1`、可换行的分类摘要行，摘要项目之间使用垂直 Divider；各具体内容分类之间使用虚线 Divider 分隔，摘要链接跳转到对应分类，分类标题在加载成功后仍保留领域图标。皮肤与炫彩分类相邻；新增皮肤卡片沿用英雄详情页的皮肤列表样式且不显示所属英雄；炫彩卡片链接到所属皮肤的炫彩区且不显示所属皮肤。加载完成后有内容的分类优先，空分类靠后；较长分类收起时完整显示前两行，并渐隐预览下一行；可在分类内独立展开。 |
| 文章 / 长文 | 标题后放导语、日期/来源和分节正文；文章 SEO 与来源要求见 [博客文章规范](../.agents/skills/blog-article/SKILL.md)。 |
| 表单任务 | 带标签的字段、字段错误、提交反馈与主/次操作；复用现有 Input、Select。 |
| 错误页 | 原因、下一步说明和返回或重试入口；404 页设置 `noindex`。 |

## 响应式适配

- 页面先用流式宽度和弹性布局；内容拥挤或阅读受影响时才切换排列，优先复用现有 480/768/1024px 断点。面包屑、标题、正文和操作保持语义顺序。
- 组件先适应容器宽度；同一组件在不同容器内确需切换布局时使用容器查询。独立控件的触控尺寸和文字链接的间距按 [DESIGN.md](../DESIGN.md#layout) 执行；悬停只作增强。
- 首页与列表：窄屏导航、筛选、卡片和适用的分页仍可操作；Masonry 在窄屏减少列数，Tree 启用展开时控件支持触控；折叠后仍能访问全部选项，横向卡片列表的单张内容可读。
- 详情：原画完整，资料与操作可达；预览和菜单避开视口边缘与安全区。长文、表单和错误页：正文可读，宽表在自身区域滚动，字段、反馈和返回入口可达。
- 验收受影响的中英文页面：320 CSS px 无页面级横向溢出，检查断点两侧、宽屏与缩放，以及触控（含鼠标与触控混合设备）、键盘、空/错误状态和减少动效；可用时再核对不同浏览器。

交付前核对所选类型、面包屑与标题顺序、版心和适用状态；验证流程见 [前端视觉统一与治理](frontend-design.md#4-流程与协作)。
