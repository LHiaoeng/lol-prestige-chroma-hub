# 页面模板契约

新增或重做页面时，先选页面类型，再按通用骨架组装；修改现有页面布局或响应式时核对对应契约。复用现有 [BaseLayout](../src/layouts/BaseLayout.astro)、[Breadcrumb](../src/components/Breadcrumb.astro) 和组件。视觉值以 [DESIGN.md](../DESIGN.md) 与 [tokens.css](../src/styles/tokens.css) 为准。

## 通用骨架

1. `BaseLayout` 接收本语言的标题、描述、canonical、locale，以及适用的结构化数据；它负责站点 Header、`<main>`、Footer、语言切换和 [返回顶部](../src/components/BackToTop.astro)。页面不重复放置返回顶部按钮。
2. 有上级的页面在 Header 下、标题前放 `Breadcrumb`。它与页面版心容器作为 `<main>` 的同级内容排列，不放进 `.runtime-page` 等已设版心或横向留白的容器，避免二次缩进；面包屑与后续第一个内容块统一间隔 `--space-3`，内容容器不再增加顶部间距。首项链接到本语言首页，中间项链接到上级，末项是当前页纯文本；文章使用 `article` 变体。首页与无确定上级的 404 页省略面包屑。
3. 页面内容使用唯一的 `h1`，下面依次放简短说明、适用的操作和主体内容；主体内容按 `h2` 分节。动态区域只负责动态结果，加载、空、错误和重试状态在此就地呈现并提供文字反馈，不改变面包屑、标题和页面版心容器的层级；CD 详情页的实体标题及面包屑末项由成功加载的实体名称填充。

## 宽度

- 列表、详情和普通页面沿用共享版心：`width: min(var(--content-width), calc(100% - (var(--page-gutter) * 2)))`，水平居中。面包屑已有相同版心，不再叠加横向留白。
- 页面默认内容容器占满共享版心，不额外缩窄，也不超过版心宽度；仅图片、专属网格、图表和浮层等有明确功能或媒体需求的元素局部限宽。
- 长文沿用 [article.css](../src/styles/article.css) 的外层版心；正文、导语、图片和表格默认使用完整版心宽度。关于页和隐私页正文同样沿用各自版心。
- 背景与原画可铺满视口，标题、正文、导航和操作仍与版心对齐。间距用现有 `--space-*`；手机边距由共享样式覆盖。

## 固定背景媒体

- 页面级背景由 [BaseLayout](../src/layouts/BaseLayout.astro) 全局加载 [backgrounds.css](../src/styles/backgrounds.css)。页面直接使用模块类，不重复导入样式，也不自行实现 `position: fixed`、视口尺寸、媒体裁切和层级。
- Header 与 Footer 由 `BaseLayout` 保留在背景之上；页面模板只放背景和页面内容，不隐藏、替换或用全屏层覆盖 Footer。
- 按页面层级选择模块类：首页使用 `page-backdrop page-backdrop--home`，并让页面建立 `isolation: isolate` 的层叠上下文、前景内容设为 `z-index: 1`；其他页面使用 `page-backdrop page-backdrop--behind`，并确保其所在页面层叠上下文隔离。详情页可额外使用 `page-backdrop--detail` 获得详情专用遮罩。背景包裹层使用 `aria-hidden="true"`，不得承载交互或唯一信息。
- 页面结构按此模式组装，背景与正文同属页面模板，但背景固定于视口：

  ```astro
  <BaseLayout title={title} description={description}>
    <div class="page-backdrop page-backdrop--behind" aria-hidden="true">
      <!-- ResponsiveHeroBackdrop 或 picture/img -->
    </div>
    <!-- 面包屑、标题和正文 -->
  </BaseLayout>
  ```

- 需要响应式取图、叠加层和已有图片回退逻辑时，在 `.page-backdrop` 内使用 [ResponsiveHeroBackdrop](../src/components/ResponsiveHeroBackdrop.astro)；详情等静态背景使用 `<picture>` / `<img>`，并给装饰图设置 `alt=""`。背景失效或不可用时，主体内容与阅读顺序保持不变。
- 固定背景不得置于带 `transform`、`filter`、`perspective` 或裁切的祖先下，以免固定定位变成局部定位或被截断；背景层不遮挡交互，Header 和前景内容保持在背景之上。
- 背景按本站断点适配：桌面（≥1024px）使用大图与宽屏遮罩；平板（768–1023px）保留大图清晰度并调整遮罩和动效；手机（≤767px）使用中图、单独调整构图和遮罩。平板与手机均关闭漂移动画，保持正文对比度并减少小屏开销。
- 背景图片以 `object-fit: cover` 填满视口；叠加渐变或遮罩，保证前景文字对比度。图片加载失败时依次尝试已配置的备用图片和占位图；都不可用时保留 `var(--bg)` 等主题纯色底，不显示破图图标。
- 背景视频同样只作装饰，静音、内联播放、循环播放并提供静态 `poster`；视频未能加载、播放或自动播放时显示 `poster`/备用图片，静态资源也失败时回退到主题纯色底。共享模块目前只提供视频的固定定位和铺满视口样式，使用视频的页面还须实现上述媒体回退；视频不承载唯一信息，不提供会抢占焦点的控件。
- 尊重 `prefers-reduced-motion`：减少动态效果时停止背景视频与视差/漂移动画，显示静态图片；自动播放受限、节省流量或媒体格式不支持时也采用静态兜底。

## 类型差异

| 类型 | 在通用骨架上补充 |
| --- | --- |
| 首页 | 可用视觉隐藏的 `h1`；主题区块用 `h2`，提供内容入口和主要目录。 |
| 列表 / 搜索 | 结果列表与空/失败状态；有筛选需求时提供筛选、排序和结果数量。内容高度不一时可使用 Masonry；数据量和任务需要分页时才提供分页。 |
| 详情 | 主媒体或关键资料、相关操作、补充资料；处理缺失字段和图片失败。以原画为视觉焦点时可隐藏 `h1`，但可见名称须清晰。 |
| 运行时资料（CD） | 默认面包屑后紧接资料版本下拉；宇宙列表紧凑排列：面包屑后显示带图标的“宇宙”标题，下一行并排显示版本下拉、垂直分割线和数量，不显示说明文案。水平与垂直分割线统一使用共享 Divider 组件，宇宙列表不在分割线前后重复叠加间距。其他列表页保留页面 H1 与简短说明，详情页由动态实体标题提供唯一 H1 并同步更新面包屑末项，PBE 对比页使用静态比较说明和页面 H1。英雄、系列和宇宙目录不分页，筛选结果全部以响应式 Masonry 展示；宇宙卡片用禁用展开控件的 Tree 常显宇宙与所属皮肤系列关系，并按节点类型显示装饰图标。动态列表首次加载时，Skeleton 按实际版式占位筛选栏与卡片（英雄含头像、名称和定位；宇宙含名称和树形系列项）；保留当前结果刷新时使用 Spin 遮罩；无匹配结果显示 Empty；加载失败显示 Alert 和重试操作。 |
| 文章 / 长文 | 标题后放导语、日期/来源和分节正文；文章 SEO 与来源要求见 [博客文章规范](../.agents/skills/blog-article/SKILL.md)。 |
| 表单任务 | 带标签的字段、字段错误、提交反馈与主/次操作；复用现有 Input、Select。 |
| 错误页 | 原因、下一步说明和返回或重试入口；404 页设置 `noindex`。 |

## 响应式适配

- 页面先用流式宽度和弹性布局；内容拥挤或阅读受影响时才切换排列，优先复用现有 480/768/1024px 断点。面包屑、标题、正文和操作保持语义顺序。
- 组件先适应容器宽度；同一组件在不同容器内确需切换布局时使用容器查询。独立控件的触控尺寸和文字链接的间距按 [DESIGN.md](../DESIGN.md#layout) 执行；悬停只作增强。
- 首页与列表：窄屏导航、筛选、卡片和适用的分页仍可操作；Masonry 在窄屏减少列数，Tree 启用展开时控件支持触控；折叠后仍能访问全部选项，横向卡片列表的单张内容可读。
- 详情：原画完整，资料与操作可达；预览和菜单避开视口边缘与安全区。长文、表单和错误页：正文可读，宽表在自身区域滚动，字段、反馈和返回入口可达。
- 验收受影响的中英文页面：320 CSS px 无页面级横向溢出，检查断点两侧、宽屏与缩放，以及触控（含鼠标与触控混合设备）、键盘、空/错误状态和减少动效；可用时再核对不同浏览器。

交付前核对所选类型、面包屑与标题顺序、版心和适用状态；验证流程见 [前端视觉统一与治理](frontend-design.md#4-流程与协作)。
