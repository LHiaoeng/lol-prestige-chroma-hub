# 页面模板契约

新增或重做页面时，先选页面类型，再按通用骨架组装；修改现有页面布局或响应式时核对对应契约。复用现有 [BaseLayout](../src/layouts/BaseLayout.astro)、[Breadcrumb](../src/components/Breadcrumb.astro) 和组件。视觉值以 [DESIGN.md](../DESIGN.md) 与 [tokens.css](../src/styles/tokens.css) 为准。

## 通用骨架

1. `BaseLayout` 接收本语言的标题、描述、canonical、locale，以及适用的结构化数据；它负责站点 Header、`<main>`、Footer、语言切换和 [返回顶部](../src/components/BackToTop.astro)。页面不重复放置返回顶部按钮。
2. 有上级的页面在 Header 下、标题前放 `Breadcrumb`。它与页面版心容器作为 `<main>` 的同级内容排列，不放进 `.runtime-page` 等已设版心或横向留白的容器，避免二次缩进。首项链接到本语言首页，中间项链接到上级，末项是当前页纯文本；文章使用 `article` 变体。首页与无确定上级的 404 页省略面包屑。
3. 页面内容使用唯一的 `h1`，下面依次放简短说明、适用的操作和主体内容；主体内容按 `h2` 分节。动态区域只负责动态结果，加载、空、错误和重试状态在此就地呈现并提供文字反馈，不改变面包屑、标题和页面版心容器的层级。

## 宽度

- 列表、详情和普通页面沿用共享版心：`width: min(var(--content-width), calc(100% - (var(--page-gutter) * 2)))`，水平居中。面包屑已有相同版心，不再叠加横向留白。
- 页面默认内容容器占满共享版心，不额外缩窄，也不超过版心宽度；仅图片、专属网格、图表和浮层等有明确功能或媒体需求的元素局部限宽。
- 长文沿用 [article.css](../src/styles/article.css) 的外层版心；正文、导语、图片和表格默认使用完整版心宽度。关于页和隐私页正文同样沿用各自版心。
- 背景与原画可铺满视口，标题、正文、导航和操作仍与版心对齐。间距用现有 `--space-*`；手机边距由共享样式覆盖。

## 类型差异

| 类型 | 在通用骨架上补充 |
| --- | --- |
| 首页 | 可用视觉隐藏的 `h1`；主题区块用 `h2`，提供内容入口和主要目录。 |
| 列表 / 搜索 | 结果列表与空/失败状态；有筛选需求时提供筛选、排序和结果数量，多页时提供分页。 |
| 详情 | 主媒体或关键资料、相关操作、补充资料；处理缺失字段和图片失败。以原画为视觉焦点时可隐藏 `h1`，但可见名称须清晰。 |
| 运行时资料（CD） | 标题和通道选择属于页面骨架；动态结果区就地呈现加载、空、错误/重试和数据版本状态。 |
| 文章 / 长文 | 标题后放导语、日期/来源和分节正文；文章 SEO 与来源要求见 [博客文章规范](../.agents/skills/blog-article/SKILL.md)。 |
| 表单任务 | 带标签的字段、字段错误、提交反馈与主/次操作；复用现有 Input、Select。 |
| 错误页 | 原因、下一步说明和返回或重试入口；404 页设置 `noindex`。 |

## 响应式适配

- 页面先用流式宽度和弹性布局；内容拥挤或阅读受影响时才切换排列，优先复用现有 480/768/1024px 断点。面包屑、标题、正文和操作保持语义顺序。
- 组件先适应容器宽度；同一组件在不同容器内确需切换布局时使用容器查询。独立控件的触控尺寸和文字链接的间距按 [DESIGN.md](../DESIGN.md#layout) 执行；悬停只作增强。
- 首页与列表：窄屏导航、筛选、卡片和分页仍可操作；折叠后仍能访问全部选项，横向卡片列表的单张内容可读。
- 详情：原画完整，资料与操作可达；预览和菜单避开视口边缘与安全区。长文、表单和错误页：正文可读，宽表在自身区域滚动，字段、反馈和返回入口可达。
- 验收受影响的中英文页面：320 CSS px 无页面级横向溢出，检查断点两侧、宽屏与缩放，以及触控（含鼠标与触控混合设备）、键盘、空/错误状态和减少动效；可用时再核对不同浏览器。

交付前核对所选类型、面包屑与标题顺序、版心和适用状态；验证流程见 [前端视觉统一与治理](frontend-design.md#4-流程与协作)。
