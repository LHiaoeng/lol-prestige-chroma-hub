# 桌面常显、手机折叠内容设计

## 目标

恢复详情页完整资料列表和首页完整筛选条件，同时保留移动端的紧凑体验。

## 交互

- 桌面与平板（宽度至少 768px）：详情资料和首页筛选表单始终可见，不显示折叠标题。
- 手机（宽度小于 768px）：两块内容各自放入原生 `details`；默认收起，点击至少 44px 高的 `summary` 展开。
- 首页手机端不再显示重复的快捷筛选按钮；展开后保留搜索、英雄、版本、分类、状态、排序、应用和清除。
- 详情页展开后保留分类、分类图标、颜色、描述、原皮、皮肤系列、皮肤宇宙、英雄、版本及相关操作。

## 响应式布局

- 首页手机筛选：搜索占整行，其余选择项两列；按钮各占一列。极窄屏仍允许字段收缩，不产生水平滚动。
- 详情手机列表：标签列采用紧凑固定宽度，值列自适应；长文本换行，操作菜单保持可触控且不越界。
- 桌面沿用现有多列筛选表单和详情双栏布局。

## 验证

- 静态契约测试确认桌面常显、手机折叠、完整字段存在且快捷筛选已移除。
- 在 320px、375px、768px 和桌面宽度验证可见性、展开交互及无水平溢出。
- 运行完整发布构建。
