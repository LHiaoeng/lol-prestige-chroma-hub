# 国服版本公告列表入口

核对时间：2026-10-16。本文只记录**公告列表**的获取方式；列表中的日期是文章发布日期。按本项目的数据口径，公告正文明确写出的停机维护日期作为该版本所列皮肤的国服发布日期。

## 指定的“版本”分类

入口是[国服官网版本列表第 1 页](https://lol.qq.com/gicp/news/423/2/1334/1.html)，后续页使用 `https://lol.qq.com/gicp/news/423/2/1334/{page}.html`。这是服务端输出的 GBK 编码 HTML，不是 JSON API。每条公告位于 `ul.news-type-list > li.newsitem`，其中 `a.item-href` 给出详情页路径和标题，`span.item-time` 给出文章日期。分页链接位于 `#J_navigation`。

本次逐页验证第 1–12 页：前 11 页各 20 条，末页 1 条，共 221 条，列表日期从 2018-01-15 到 2026-10-08。页数和条目数会随官网更新变化，应从页面分页链接读取末页，而非长期写死为 12。第 1 页的 `.json` 变体返回 404；添加 `?format=json` 仍返回 HTML。页面源码中列表项和分页链接已存在，不依赖客户端请求列表接口。尚未找到与此 **同一分类** 对应的公开 JSON 接口。

示例：

```text
GET https://lol.qq.com/gicp/news/423/2/1334/1.html
Content-Type: text/html

<li class="newsitem">
  <span class="item-type">版本</span>
  <a class="item-href" href="/gicp/news/410/37098539.html">26.20版本更新公告</a>
  <span class="item-time">2026-10-08</span>
</li>
```

## 另一个官网 JSON 接口的边界

官网[新闻列表页](https://lol.qq.com/news/index.shtml)加载的[脚本](https://lol.qq.com/v3/js/newslist.js)调用以下接口；其中 `target=24` 对应“公告”标签页：

```text
GET https://apps.game.qq.com/cmc/zmMcnTargetContentList?r0=json&page=1&num=30&target=24&source=web_pc
```

已验证响应为 JSON，`data.result` 是当页文章，`data.resultTotal` 是总数，`page` 和 `num` 控制分页。文章常见字段包括 `iDocID`、`sTitle`、`sCreated`、`sRedirectURL`。但它是**混合公告**：本次第 1 页同时含版本更新、每周免费英雄、活动和云顶之弈内容；`target=1334` 在该接口返回空列表。因此不能把它直接当成指定“版本”分类的全量 API。它可以辅助发现较新的公告，最终仍需按标题、正文和详情链接核对。

两套来源可通过**详情页 URL 的路径**关联。本次抓取 HTML 12 页的 221 条，以及 JSON 接口全部 2610 条后，按 `sRedirectURL` 与 HTML `a.item-href` 的 URL pathname 匹配到 193 条；另外 28 条 HTML 公告没有出现在 JSON 结果中，集中在较早年份。匹配的 193 条中，22 条标题文字不同，1 条发布日期不同。因此不要用标题、日期或 JSON `iDocID` 关联；例如 HTML 的 `/gicp/news/410/37098539.html` 与 JSON 的 `sRedirectURL` 对应，但 JSON `iDocID` 是 `1831486045361164057`。URL 可能使用 `http` 或 `https`，比较时只取同域详情页的 pathname。

## 对发布时间数据的用途

先从版本列表取得详情页 URL，再从正文核对版本号、停机维护日期和该版本所列皮肤。公告标题或正文中的版本号与明确列出的皮肤对应时，版本号可回填 `chinaReleaseVersion`；按本项目口径，停机维护日期回填 `chinaReleaseDate`。例如[26.20 版本公告](https://lol.qq.com/gicp/news/410/37098539.html)于 2026-10-08 发布，正文明确写 10 月 9 日凌晨 1 点开始全区停机维护，并列出“以下皮肤已在 26.20 版本内”，这些皮肤记录版本 `26.20`、日期 `2026-10-09`，而不是文章发布日期 `2026-10-08`。无法从正文确认版本号、维护日期或皮肤归属时，相应字段保持空值并报告。
