# 皮肤边框数据源调研

- 调研时间：2026-09-30
- 调研渠道：CommunityDragon `pbe`（并与 `latest` 正式服对比）
- 背景：PBE 新增的 HEARTSTEEL（心之钢）「Live My Life」系列皮肤全部带载入边框，但 `v1/skinborders.json` 中没有对应条目，需要确认边框数据还保存在哪里。

## 结论速览

皮肤边框数据在 CD 上一共有 **三个**保存位置，分属三代机制：

| # | 位置 | 形态 | PBE 数量 | 心之钢新皮肤 |
|---|------|------|----------|--------------|
| 1 | `v1/skinborders.json` | 边框战利品/库存道具目录，含 PNG 路径 | 93 条 | 无 |
| 2 | 皮肤对象的 `skinAugments.borders`（`v1/champions/{id}.json` 与 `v1/skins.json`） | 运行时叠加 PNG 的分层指令（layer/priority） | 17 个皮肤 / 77 个边框引用 | 无 |
| 3 | 皮肤对象的 `loadScreenVintagePath`（同上两个文件） | **边框已烘焙进画面的独立 JPG**（文件名 `_LE` 后缀） | 855 个皮肤 | **全部在这里** |

三者关系：来源 2 引用的 77 个边框 PNG **全部**能在来源 1 的 `image` 字段中找到；来源 3 与前两者互不重叠，是心之钢这类"系列附赠边框"的唯一交付方式。

## 来源 1：`v1/skinborders.json`

全局边框道具目录，PBE 与正式服均为 93 条（PBE 无新增）。

```json
{
  "name": "Hall of Legends 2024: Risen Legend Border",
  "itemId": 5,
  "contentId": "d4de70bc-ecfc-42ff-91bb-7a7340ba5a52",
  "image": "/lol-game-data/assets/ASSETS/Characters/Ahri/Skins/Skin85/UI/AhriLoadScreen_Augments_Border_Starter.png"
}
```

要点：

- `itemId` 是**边框自身的道具 ID，不是皮肤 ID**（如 Victorious Draven 段位边框为 60–69，皮肤 ID 是 119068）。
- 边框归属哪个皮肤只能从 `image` 路径中的皮肤目录反推，或由客户端合成配方/`contentId` 关系决定（该配方不在这些 JSON 中）。
- 覆盖内容：胜利皮肤（Victorious）各段位边框、名人堂（Hall of Legends）Starter/Premium/Immortalized/Signature、双城之战 Jinx、Sahn-Uzal Mordekaiser 等，即来源 2 所引用素材的战利品化目录。
- 93 条比来源 2 的 77 个引用多出的部分是合成升级类道具（如 Faker/Uzi/Caps 的 Signature 升级）。

## 来源 2：`skinAugments.borders`（运行时叠加 PNG）

位于英雄详情 JSON（`v1/champions/{champId}.json`）每个皮肤对象上；平铺集合 `v1/skins.json` 中同一皮肤也带此字段，内容一致。PBE 上共 17 个皮肤使用。

结构：`layer0` / `layer1` 自下而上叠加；同层多条为互斥备选项，按 `priority` 取一；`borderPath` 指向边框 PNG。

```json
"skinAugments": {
  "borders": {
    "layer0": [
      { "priority": 0, "borderPath": "/lol-game-data/assets/.../LeblancLoadScreen_Augments_Border_Starter.png" },
      { "priority": 1, "borderPath": "/lol-game-data/assets/.../LeblancLoadScreen_Augments_Border_Premium.png" }
    ],
    "layer1": [
      { "priority": 0, "borderPath": "/lol-game-data/assets/.../LeblancLoadScreen_Augments_Border_Signature.png" }
    ]
  }
}
```

覆盖内容：2024/2025 胜利皮肤（Iron→Challenger 10 档）、名人堂 Risen Legend 系列、Arcane Fractured Jinx、Spirit Blossom Morgana、Sahn-Uzal Mordekaiser、Radiant Serpent Sett、Revenant Reign Viego 等。

实测：77 个 `borderPath` 引用与来源 1 的 `image` **100% 重合**，即来源 2 是同一批 PNG 的"运行时合成说明书"。

## 来源 3：`loadScreenVintagePath`（预烘焙边框 JPG）★心之钢所在

每个皮肤对象都有 `loadScreenPath`（无边框普通载入图）；当皮肤带系列边框时，会**额外**提供 `loadScreenVintagePath`，指向一张把边框直接画进画面的 JPG。PBE 上共 **855** 个皮肤有此字段，最早可追溯到 FrankenTibbers Annie（1007）。

以 PBE Ezreal 为例（两条 URL 实测均为 308×560）：

```
loadScreenPath:        .../Skin78/EzrealLoadScreen_78.SKINS_Ezreal_Skin78.jpg
loadScreenVintagePath: .../Skin78/EzrealLoadScreen_78_LE.SKINS_Ezreal_Skin78.jpg
```

- `_LE` 是带边框版本的固定文件名标记。
- 皮肤目录下**不存在**可叠加的边框 PNG（已对 UI 目录下多种候选文件名探测，全部 404），边框只存在于这张烘焙 JPG 中。
- 这批皮肤在 `skinborders.json` 中无条目、`skinAugments` 为 `null`。

## PBE 新增心之钢皮肤实测

系列 ID：HEARTSTEEL = 199（`v1/skinlines.json`）。PBE 新增 6 个皮肤（另各有 1 个 Ruby/Vivid 炫彩），全部仅靠来源 3 交付边框，6 个 `_LE` 文件 HEAD 均为 200：

| 皮肤 ID | 名称 | 稀有度 |
|---------|------|--------|
| 81078 | HEARTSTEEL Live My Life Ezreal | Epic |
| 141032 | HEARTSTEEL Live My Life Kayn | Epic |
| 523041 | HEARTSTEEL Live My Life Aphelios | Epic |
| 777077 | HEARTSTEEL Live My Life Yone | Epic |
| 897018 | HEARTSTEEL Live My Life K'Sante | Epic |
| 875076 | Prestige HEARTSTEEL Live My Life Sett | Mythic |

对比下载的 Ezreal 两张图：普通载入图无边框；`_LE` 版两侧有紫色闪电边框、底部有六名成员头像与心之钢星形装饰，原画部分完全相同。

2023 年的初代心之钢 7 个皮肤（81043、141020、523030、777045、777046、875056、897008）同样只存在 `loadScreenVintagePath`，不在 `skinborders.json` 中。

## 对本站的影响（最终方案，已实现）

- 「媒体」网格只显示无边框原版载入图；媒体区块之后渲染独立「边框 / Borders」section。
- vintage 皮肤（含心之钢初代与 Live My Life）：直接展示 `loadScreenVintagePath` 的烘焙 JPG，不做合成、不出切换器，提供成品 JPG 下载。
- augment 皮肤：载入图 + 分层边框叠加；同层多个互斥项以「左切换 + 右下拉下载」呈现（默认最高 priority），切换仅替换叠加层 src。下载下拉菜单提供：该变体边框 PNG 单独下载；canvas 合成当前全部已选图层导出的合成效果图 JPG。
- 判定入口为 domain 纯函数 `resolveBorderModule`（baked 优先于 composite），配套 `listBorderGroups`、`borderVariantLabel`。
