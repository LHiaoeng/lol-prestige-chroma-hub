# 英雄联盟资料页面信息规范

> 状态：已确认的信息范围，尚不表示对应页面与字段已经全部实现。

本文定义 LoL Chroma Art 借鉴国服与直营服 Skin Explorer 时，各英雄联盟资料页面展示哪些信息。本文不决定数据加载架构、路由形式、布局、交互或 SEO 策略。

参考项目：

- [国服 Skin Explorer](https://github.com/BuguoguoLoLCreator/lol-skin-explorer)
- [直营服 Skin Explorer](https://github.com/BennyExtreme00/lol-skin-explorer)

## 1. 范围边界

- 首页、臻彩详情页和博客保持现有信息范围，不因本规范增加、删除或改写内容。
- 资料范围包括英雄目录与详情、皮肤详情、皮肤系列目录与详情、皮肤宇宙目录与详情，以及独立的 PBE 新增页面。
- 不提供皮肤目录页；皮肤从英雄、皮肤系列、皮肤宇宙或 PBE 新增资料进入详情。
- 页面只展示当前本地化视图存在的事实；英文使用 `default`，简体中文使用 `zh_cn`，缺失字段不跨本地化视图或数据通道补值。`default` 和 `zh_cn` 是数据源 token，不作为服务器名称展示。
- CommunityDragon 实体使用数字 ID 识别，不根据名称、slug 或皮肤 ID 的数字结构猜测身份。

## 2. 页面信息范围

| 页面 | 展示信息 |
| --- | --- |
| 英雄目录 | 英雄名称、英雄头像、英雄定位 |
| 英雄详情 | 英雄名称、英雄默认外观原画，以及该英雄全部皮肤的名称、缩略图和稀有度 |
| 皮肤系列目录 | 皮肤系列名称 |
| 皮肤系列详情 | 系列名称、所属皮肤宇宙，以及系列内皮肤的名称、缩略图和稀有度 |
| 皮肤宇宙目录 | 皮肤宇宙名称及其包含的皮肤系列名称 |
| 皮肤宇宙详情 | 皮肤宇宙名称、描述、所属皮肤系列，以及按系列归类的皮肤名称、缩略图和稀有度 |
| 皮肤详情 | 名称、稀有度、描述、所属英雄、皮肤系列、皮肤宇宙、媒体、历史版本原画、炫彩和对应第三方入口 |
| PBE 新增 | PBE 与正式服的版本信息、新增实体总数和分类数量，以及新增英雄、皮肤、皮肤系列和皮肤宇宙 |

目录和详情中的皮肤资料只包含参考项目实际使用的皮肤字段，不扩展到技能、出装、符文、胜率或职业比赛数据。

## 3. 皮肤详情

### 3.1 核心资料

- 皮肤名称与稀有度。
- 所属英雄、皮肤系列和皮肤宇宙。
- 皮肤描述。
- 聚焦原画、未裁剪原画、缩略图、载入图和数据源实际提供的动态原画。
- 数据源实际提供的历史版本及对应原画。

### 3.2 多阶段皮肤

- 每个具有有效正整数 ID 的皮肤阶段生成一个独立可查看的皮肤资料项，并拥有自己的名称、原画、动态原画和炫彩；该资料项不因此成为新的 CommunityDragon 实体。
- 阶段自身的名称和媒体优先；阶段缺少描述、稀有度、皮肤系列或皮肤宇宙时，继承所属皮肤在同一数据通道和本地化视图中的对应事实。
- 不跨语言或数据通道继承字段，也不为缺少有效 ID 的阶段补造身份。

### 3.3 炫彩

- 炫彩数量只统计真正的炫彩，不包含皮肤本身。
- 炫彩区域同时显示一个皮肤本体项和全部炫彩；中文可见文案使用“默认配色”，英文使用 `Base`，无障碍说明明确它不是炫彩。
- 皮肤本体项不携带炫彩颜色，不进入炫彩数量。
- 每个炫彩展示数据源提供的名称、图片和颜色；缺失字段保持缺失，不从其他本地化视图补值。
- 现有臻彩页面使用的颜色组件保持原有默认语义；非炫彩状态只服务于皮肤资料中的皮肤本体项。

### 3.4 第三方入口

英文皮肤详情（`default` 本地化视图）沿用直营服参考项目的入口：

- SkinSpotlights：按皮肤名称查找演示视频。
- Teemo.GG：查看对应英雄与皮肤的 3D 模型。

简体中文皮肤详情（`zh_cn` 本地化视图）沿用国服参考项目的入口：

- 布锅锅语音站：按英雄 ID 查看所属英雄语音。
- 哔哩哔哩：按中文皮肤名称查找演示视频。
- 布锅锅 3D 模型站：按完整皮肤 ID 查看模型。

两种语言不合并第三方入口，也不自行维护额外网站名单。第三方入口只属于皮肤详情，不加入首页、臻彩详情页或博客。

## 4. PBE 新增

PBE 新增页面集中展示同一本地化视图下存在于 `pbe`、但不存在于 `latest` 的实体。页面标题与玩家文案使用“PBE 新增”，内部比较仍使用数据源 token；它不承担已有实体字段变化的展示职责。

页面展示：

- PBE 与正式服的版本信息；技术详情可附带 `pbe` 与 `latest` token。
- 新增实体总数，以及英雄、皮肤、皮肤系列和皮肤宇宙的分类数量。
- 新增英雄：名称、头像。
- 新增皮肤：名称、缩略图、稀有度、所属英雄。
- 新增皮肤系列：系列名称。
- 新增皮肤宇宙：宇宙名称及其包含的皮肤系列。

已有实体的名称、描述、稀有度或媒体变化属于通道间变化，不计入 PBE 新增；未来如需展示，应另行定义变化范围。

## 5. 明确不在本次范围内

- 修改首页、臻彩详情页或博客的信息。
- 新增皮肤目录页。
- 展示技能、装备、符文、对局统计或电竞数据。
- 把已有实体的字段变化混入 PBE 新增。
- 为缺失数据猜测默认值、身份或跨区域回退值。
- 决定具体视觉样式、交互方式、路由或数据加载架构。

## 6. 与现有架构决策的关系

本规范记录已确认的页面信息目标，不自动修改 [ADR-0002：将 CommunityDragon 资料移至浏览器运行时](./adr/0002-load-communitydragon-reference-at-browser-runtime.md)。其中两项内容与 ADR-0002 的当前实现边界存在待解决冲突：

- 本规范要求皮肤系列详情和皮肤宇宙详情展示关联皮肤；ADR-0002 当前不在皮肤系列或皮肤宇宙页面反向承诺完整皮肤集合。
- 本规范要求 PBE 新增页面完整列出新增皮肤；ADR-0002 当前拒绝把完整 `skins.json` 作为默认运行时依赖。

实施前应另行决定如何取得可验证的完整关系与 `pbe` / `latest` 差异，并在需要时修订或取代 ADR-0002。解决该架构问题前，ADR-0002 继续约束现有实现，本规范不表示冲突功能已经上线。
